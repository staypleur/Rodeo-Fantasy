# 이전 몬스터 검토 모델 보관

사용자가 새 몬스터 모델을 제공하기로 하여 기존 모스랫/브램블보어/바인팽 검토 모델과 연결된 OBJ/MTL/색 텍스처 54개를 원래 상대 경로 구조대로 보관했다. `manifest.json`에 이동 전후 SHA256을 기록했다. 새 숲 맵은 이 모델을 사용하지 않는다.

사용자 Meshy 원본, 리깅 원본, 기존 게임을 다시 빌드하는 데 필요한 입력 및 이미 설치된 개인 Studio 장소는 보존했다. 로비 비행선은 이번 몬스터 교체 대상으로 취급하지 않았다. 기존 실행 코드의 몬스터 참조를 제거한 것은 아니며, 새 모델 적용 때 교체를 진행한다. 이 폴더의 모델은 새 사냥터의 최종 콘텐츠가 아니다.

복구가 필요하면 manifest의 source 경로로 해당 파일을 되돌릴 수 있다. 옛 검토 생성 도구는 아직 과거 경로로 출력을 만들 수 있으므로 새 제작에서 실행하지 않는다.
