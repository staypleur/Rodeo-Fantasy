# 새 사냥 몬스터 모델 입력

사용자가 새 모델을 제공하기 전까지 비어 있는 준비 폴더다. 새 이름·형상·별 단계·속도·능력은 임의로 확정하지 않는다. 이전 검토 모델은 `archive/legacy-monsters/2026-10-10`에서 보관하며 새 숲 맵에 등장하지 않는다.

모델을 받으면 원본을 그대로 보존하고 다음 항목을 실제 파일에서 검사한다.

- 파일 형식, 삼각형 수, 메시·텍스처·리깅 구조, 실제 얼굴 방향과 크기.
- 달리기/점프용 뼈나 클립 존재 여부, 등에 앉는 위치와 캐릭터가 겹치는지.
- 모바일용 형상·텍스처 예산과 실제 PC/모바일 표시·성능.
- 기존 점프·줄 입력을 사용하는 개인 사냥 시스템의 템플릿·외형·서버 충돌 연결.

맵 데이터(`StudHuntLayout`)와 맵 생성기(`StudBlockMapGenerator`)는 특정 몬스터 종류/이름/템플릿에 의존하지 않는다. 새 모델 크기에 맞춰 통로와 충돌을 검증한 뒤, 후방 추적 시점 및 실제 사냥 런타임을 연결한다. 기존 가방·도감·획득 기록은 모델 교체만으로 삭제하지 않는다.

최종 화면 구성 목표는 빈 공간40%·장애물20%·몬스터40%다. 등장 개수 비율로 계산하지 않는다. 후방 카메라와 PC/모바일 화면비, 새 몬스터의 실제 표시 크기를 확인해 배치와 주변 표시량을 조절한다. 기본 Stud 표면은 바닥·나무·바위·벽에 유지한다.
