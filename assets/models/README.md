# 앰버랫 B 기본형

- 사용자 선택: 2026-10-07, 불꽃 수정 시안 B.
- 기준 이미지: [B가 포함된 시안](../concepts/emberrat-base-options-v2-fire.png).
- 모델: [Emberrat-B.rbxmx](../../dist/Emberrat-B.rbxmx).
- 적용된 테스트 장소: [RodeoFantasy-Capture.rbxlx](../../dist/RodeoFantasy-Capture.rbxlx).
- 편집 원본: [모델 형태와 색상](../../tools/emberrat_model.py).

날렵한 네발 체형, 큰 귀, 긴 곡선 꼬리, 주황빛 갈색 몸과 크림색 얼굴/배를 표현했다. 머리와 꼬리 끝의 작은 불꽃은 밝은 부품과 Roblox `Fire` 효과로 표현한다.

67개 외형 부품과 보이지 않는 탑승 기준 부품으로 구성했다. 별도 에셋 업로드, 외부 모델, 플러그인이 필요 없다. 시안의 형태를 Roblox 기본 부품으로 재현한 첫 게임용 모델이며, 이미지와 동일한 세밀한 메시/텍스처를 사용하는 것은 아니다.

모델 중심의 `MountRoot`는 기존 탑승 원점과 같아서 전체 모델이 함께 이동한다. 외형 부품은 충돌하지 않으며 `Model:PivotTo`로 움직인다. 캐릭터를 태우는 코드는 포획 테스트 장소에 들어 있다. 개별 모델 파일에는 외형만 포함한다.

이번 파일은 기본형 외형만 포함한다. 포획 테스트 장소에서는 `RideAnimator`가 다리 움직임/기울기를 계산한다. 개별 모델 파일에는 이 코드가 포함되지 않는다. 3성·6성·9성 진화 외형과 정교한 리깅은 별도 작업이다.
