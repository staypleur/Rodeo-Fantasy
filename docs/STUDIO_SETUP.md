# 앰버랫 탑승·포획 테스트 시작하기

## 1. 테스트 파일 열기

1. Roblox Studio를 실행합니다.
2. 상단 **File(파일) → Open from File(파일에서 열기)**를 누릅니다. Windows에서는 **Ctrl+O**로 파일 열기 창을 띄울 수도 있습니다.
3. 바탕 화면의 **Project → Rodeo Fantasy → dist** 폴더로 이동합니다.
4. **RodeoFantasy-Capture.rbxlx** 파일을 선택하고 엽니다.
5. 모래색 바닥과 큰 귀·긴 꼬리·작은 불꽃이 있는 앰버랫 B 모델이 들어 있는 테스트 장소가 열립니다.

GitHub에서 받는 경우 `dist/RodeoFantasy-Capture.rbxlx` 파일 페이지의 **Download raw file** 버튼으로 다운로드하세요. 웹페이지 자체를 저장하면 안 됩니다.

## 2. 캐릭터로 실행하기

1. 상단의 **Play(재생, 삼각형 버튼)**를 누르거나 **F5**를 누릅니다. 캐릭터 없이 실행하는 Run 모드는 사용하지 마세요.
2. 캐릭터가 나타나면 게임 화면 안을 한 번 클릭합니다.
3. 화면 아래에 **3m 안의 앰버랫을 클릭하세요**라는 안내가 보이는지 확인합니다.
4. **W/A/S/D**로 앰버랫에 가까이 갑니다. 앰버랫 위에 마우스를 올리면 거리가 표시됩니다.
5. **3m 안**에서 앰버랫을 클릭합니다. 줄이 연결되고 캐릭터가 점프해 올라갑니다.
6. 탑승 후에는 자동으로 앞으로 갑니다. **A는 왼쪽, D는 오른쪽**입니다.
7. 탑승 후 3초가 지나면 화면 아래에 판정 막대가 나타납니다.

## 3. 포획하기

막대가 원하는 구역에 왔을 때 **스페이스바**를 누릅니다. 노란색을 맞혀도 미니게임은 끝나지 않고 계속됩니다.

| 판정 | 결과 |
| --- | --- |
| 흰색 | 즉시 떨어집니다. 같은 앰버랫에 가까이 가서 다시 클릭하면 재도전합니다. |
| 노란색 | 버티기를 유지합니다. 첫 노란색부터 5초가 지나면 포획하며, 그동안 막대와 스페이스바 판정이 계속됩니다. 다시 노란색을 맞혀도 5초가 초기화되지 않습니다. |
| 주황색 | 즉시 포획합니다. |

처음에는 흰색 85% / 노란색 14% / 주황색 1%입니다. 같은 테스트 실행에서 앰버랫을 한 번 포획하면 다음 시도는 80% / 17% / 3%가 됩니다.

예를 들어 첫 노란색 뒤 2초가 지나 다시 노란색을 맞히면 **3초가 남습니다**. 이때 흰색을 누르면 즉시 떨어지고, 주황색을 누르면 남은 시간과 관계없이 즉시 포획합니다. A/D 이동도 계속 가능합니다.

성공하면 **포획 성공!** 문구와 **이번 접속 앰버랫 포획: 1마리**가 표시됩니다. 반복 테스트를 위해 그 자리에 1초 후 새 앰버랫이 나타납니다. 이 재생성 방식은 테스트 장치이며 정식 게임의 생성 규칙은 아닙니다.

## 4. 테스트 끝내기

- 상단 **Stop(정지, 사각형 버튼)** 또는 **Shift+F5**를 누릅니다.
- 다시 Play를 누르면 처음부터 시작하며 포획 수는 0으로 초기화됩니다.
- 직접 편집한 파일을 보관할 때는 **File → Save to File As**로 별도 이름을 사용하세요. 배포 파일은 다음 코드 업데이트 때 다시 생성됩니다.

## 이번 버전에서 확인할 것

- 선택한 B 시안을 Roblox 기본 부품으로 재현한 첫 기본형 모델입니다. 탑승 중에는 다리가 움직이고 좌우 조작에 따라 몸이 조금 기울어집니다. 진화형과 정교한 리깅은 이후 작업입니다.
- 영상 참고 버전에서는 탑승 카메라가 높아져 앞길이 넓게 보입니다. 바닥 양옆 표식이 뒤로 지나가며 이동감을 보여줍니다. 표식은 테스트용이며 장애물이 아닙니다. 갈아타기는 규칙 확인 중이므로 아직 할 수 없습니다.
- 맵은 탑승 테스트용 평지입니다. 이동에 따라 바닥이 이어지며, 정식 황무지 지역이나 보스는 아직 없습니다.
- 포획 수는 현재 접속에서만 유지됩니다. 게임을 종료하고 다시 들어올 때 저장되는 기능은 이후 단계입니다.
- 동물원 배치는 폐기했습니다. 포획한 앰버랫은 가방에 들어가고, 각 마리의 포획 시점부터 2초마다 1원을 쌓습니다. 화면 왼쪽 위의 **가방 / 모인 돈** 숫자가 증가하는지 확인하세요. 전시하거나 소환하지 않아도 수익이 발생합니다.
- 직접 수령 조작과 펫 동행 수는 확인 중이어서 아직 수령 버튼이나 펫 소환 기능은 없습니다. 현재 가방과 돈은 Stop 후 다시 Play하면 초기화됩니다.
- 3성·6성·9성 진화 기획은 설정에 기록했으며, 진화 동작과 외형은 아직 구현하지 않았습니다.
- PC 마우스·키보드 조작 버전입니다.

## 문제가 생기면

- 캐릭터가 없으면 Stop을 누르고 **Play(F5)**로 다시 실행하세요.
- 클릭해도 안 타지면 앰버랫에 더 가까이 가고, 화면 아래 안내를 확인하세요.
- 오류가 뜨면 **Window → Output(출력)**을 열고 빨간 오류 문장을 복사해서 보내주세요. 메뉴 위치가 다르면 보이는 화면을 보내주셔도 됩니다.
- 화면에서 누른 색과 결과가 다르면 알려주세요. 현재 서버에 입력이 도착한 시각으로 판정하므로 온라인 지연 보정은 실제 플레이 확인 후 조정해야 합니다.

## 기존 파일에서 새 모델 보기

1. 실행 중이면 **Stop(Shift+F5)**을 누릅니다.
2. 열려 있는 이전 테스트 파일 탭을 닫습니다. 직접 수정한 것이 있다면 먼저 별도 파일로 저장하세요.
3. **Ctrl+O**로 프로젝트 `dist` 폴더의 최신 **RodeoFantasy-Capture.rbxlx**를 다시 엽니다.
4. **F5**를 눌러 앰버랫 B 모델과 불꽃이 나타나는지 확인합니다.

## 모델만 다른 장소에 넣기

포획 테스트 파일에는 이미 모델이 들어 있습니다. 다른 장소에서 외형만 사용할 때 다음 순서로 넣으세요.

1. Studio에서 원하는 장소를 엽니다.
2. **Window → Explorer**에서 탐색기를 열고 **Workspace**를 마우스 오른쪽 버튼으로 누릅니다.
3. **Insert from File(파일에서 삽입)**을 선택해 `dist/Emberrat-B.rbxmx`를 엽니다.
4. 탐색기에서 **Emberrat_B**를 선택하고 **F**를 누르면 모델이 화면 가운데로 보입니다.
5. 이 파일은 외형만 포함합니다. 탑승·포획 테스트는 **RodeoFantasy-Capture.rbxlx**에서 진행하세요.
