# 파이리 사냥 테스트

## 새 파일 열기

1. Roblox Studio에서 실행 중이면 **Stop / Shift+F5**를 누릅니다.
2. 이전 장소 탭을 닫습니다. 직접 편집한 내용은 **File → Save to File As**로 다른 이름에 먼저 저장하세요.
3. **File → Open from File / Ctrl+O**를 누릅니다.
4. 바탕 화면 **Project → Rodeo Fantasy → dist**의 **RodeoFantasy-Capture.rbxlx**를 엽니다.
5. **Play / F5**로 실행합니다. 캐릭터 없이 실행하는 Run은 사용하지 마세요.

## 조작

1. 화면 중앙 **사냥 시작**을 누릅니다. 파이리를 타고 앞으로 달립니다.
2. 게임 화면 빈 곳에서 **마우스 왼쪽 버튼을 누른 채 좌우로 움직이세요**. **A/D**로도 조종할 수 있습니다.
3. **누르고 있던 버튼을 떼면 앞으로 점프**합니다.
4. 공중에서 노란 줄 범위 안에 다음 파이리가 있을 때 **다시 누르세요**. 자동으로 줄을 연결해 올라탑니다. 계속 누르고 달립니다.
5. 같은 파이리를 오래 타면 진행 표시가 차며 **길들이기 성공**과 가방 마릿수 증가가 표시됩니다.
6. 파이리가 화났다는 경고가 나오면 손을 떼고 다음 파이리로 점프하세요.
7. 바위에 부딪히거나 공중에서 다음 파이리를 잡지 못하면 종료됩니다. **다시 사냥하기**로 재시작합니다.

터치는 화면 빈 곳 누르기/떼기/좌우 움직임으로 대응합니다. 실제 기기의 터치 체감은 추가 확인이 필요합니다.

## 확인할 것

- 앞길에 파이리 무리가 달리고 바위가 나타납니다.
- 색깔 판정 막대가 없습니다. 오래 타면 길들이기 진행 표시가 차오릅니다.
- 가방 마릿수와 모인 돈이 증가하며 사냥 재시작은 이를 유지합니다.
- 시험용 길들이기/화남/속도 수치는 설정에서 조정할 수 있습니다. 원작과 똑같은 수치로 검증된 값은 아닙니다.
- 영구 저장은 아직 없습니다. **Stop 후 Play는 가방과 돈을 초기화**합니다.

## 문제 확인

오류가 나오면 **Window → Output**을 열고 빨간 문장을 보내주세요. 자동 복구 저장 충돌이 다시 생기면 새 이름으로 저장하고 Studio 창을 모두 닫은 뒤 파일 하나만 다시 엽니다.

파이리 외형만 다른 장소에 넣으려면 Explorer의 **Workspace → 마우스 오른쪽 → Insert from File**에서 **dist/Charmander.rbxmx**를 선택하세요. 이 파일에는 사냥 코드가 없으므로 테스트는 장소 파일에서 합니다.
