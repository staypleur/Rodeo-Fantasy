# 로비와 루미돈 사냥터 테스트 적용

## 새 파일 열기

1. Roblox Studio에서 실행 중이면 **Stop / Shift+F5**를 누릅니다.
2. 이전 장소 탭을 닫습니다. 직접 편집한 내용은 **File → Save to File As**로 다른 이름에 먼저 저장하세요.
3. **File → Open from File / Ctrl+O**를 누릅니다.
4. 바탕 화면 **Project → Rodeo Fantasy → dist → RodeoFantasy-Capture.rbxlx**를 엽니다.
5. **Play / F5**로 실행합니다. 캐릭터 없이 실행하는 Run은 사용하지 않습니다.

## 조작과 성공 확인

1. 처음에는 **파스텔 로비**에 나타납니다. 중앙 광장 둘레에 개인 구역 8개가 있고 각 구역에 목장 8개가 있습니다. 내 이름이 적힌 구역 간판을 확인하세요.
2. **비행장**의 ‘사냥터로 출발’ 안내판으로 걸어가 **E를 잠깐 누릅니다**. 첫 루미돈으로 날아가 탑승한 뒤 자동 전진합니다.
3. **A/D**로 좌우 이동합니다. 마우스를 누른 채 좌우로 끄는 조작도 지원합니다. 마우스를 떼어도 점프하지 않습니다.
4. **스페이스바를 한 번 누르면 점프**합니다. 공중에서 팔과 다리가 좌우로 벌어지고 노란 줄 범위가 나타납니다.
5. 원 안에 다음 몬스터가 들어오면 **스페이스바를 다시 누릅니다**. 줄이 연결되고 탑승합니다. 탑승하는 중 누른 키는 착지 후 새 점프로 예약되지 않습니다.
6. 타고 있는 몬스터의 화면 왼쪽 아래 **분홍색 원형 게이지와 하트**가 찹니다. 게이지가 가득 차면 포획되고 하트 게이지는 사라집니다. 가방 마릿수는 로비로 돌아가 확인합니다. 같은 개체로 계속 달릴 수 있습니다. 달릴 때 하단 설명창은 숨깁니다.
7. 먼저 **느낌표(!)** 경고가 깜빡인 뒤 반복해서 뛰면서 좌우로 튕깁니다. 평소보다 방향 전환도 어려워집니다. 길들여진 루미돈도 똑같이 화나며, 화났다는 이유만으로 자동으로 떨어지지 않습니다. 계속 타거나 **스페이스바로 자발적으로 점프**해 갈아탈 수 있습니다.
8. 주행 중 다른 몬스터나 벽에 닿으면 즉시 종료됩니다. 플레이어 몸 부품이 흩어졌다 사라집니다. **벽이나 장애물에 부딪히면 타고 있던 몬스터도 함께 부서집니다**. **다시 사냥하기**를 누르면 플레이어가 다시 보이고 재도전합니다.
9. **착지 보호 시간은 없습니다.** 첫 탑승과 갈아타기 직후에도 나무·바위를 피해야 하며, 닿으면 바로 사냥이 끝납니다.

터치는 화면의 **점프 / 줄** 버튼과 좌우 드래그로 대응합니다. 실제 기기 체감은 별도 확인이 필요합니다.

가방 보유와 수익은 이번 접속에서만 유지됩니다. 사냥 재시작은 유지하지만 **Stop 후 Play는 초기화**됩니다. 카페·영구 저장·합성과 진화는 아직 이 파일에 없습니다.

## 외형만 삽입

다른 장소의 **Explorer → Workspace 마우스 오른쪽 → Insert from File**에서 **dist/Lumidon.rbxmx**를 선택합니다. 외형 파일에는 사냥 코드가 없으므로 사냥 테스트는 장소 파일을 엽니다.

## 문제 확인

오류가 나오면 **Window → Output**을 열어 빨간 문장을 확인합니다. 자동 복구 저장 충돌이 생기면 새 이름으로 저장하고 Studio 창을 닫은 뒤 파일 하나만 다시 엽니다.

## 이번 화면 개선 확인

루미돈 몸통이 평상시에 빠르게 떨리지 않고 다리만 크게 뻗으며 달리는지 확인합니다. 화났을 때의 반복 점프와 좌우 튕김은 의도한 동작입니다. 분홍 게이지, 좌우로 뻗는 공중 팔다리, 충돌 부품 연출은 실제 Play에서 확인하세요.

## 앉는 자세와 주행 연출 확인

첫 탑승 뒤 다리를 앞으로 굽혀 앉고, 오른팔을 들어 머리 위에서 황금색 줄을 돌리는지 확인합니다. 점프하면 회전 줄이 사라지고 팔·다리를 펼치는 공중 자세로 바뀝니다. 착지 먼지, 지나가는 지면 바람 자국, 루미돈 귀·꼬리 움직임과 좌우 기울기도 확인하세요.

이번 시험판은 거리 1,000m에서 길 바닥선과 양쪽 표지판을 지나가며 멈춥니다. 처음부터 1,000m 표지가 바로 앞에 있는 것은 아닙니다.

## 무리와 장애물 회피 확인

플레이어가 타지 않은 루미돈들이 앞으로 달리면서 각자 다른 리듬으로 좌우 이동하고 바위 앞에서 빈 쪽으로 피하는지 확인합니다. 플레이어가 탄 루미돈은 A/D로 직접 피해야 합니다.

이전보다 몬스터 배치 빈도는 약 절반, 기존 바위 배치 빈도는 약 1.5배입니다. 무작위 배치라 화면마다 실제 수는 달라집니다. 바위가 갑자기 아주 가까이 생기면 타지 않은 몬스터는 잠깐 전진을 멈추고 옆으로 피합니다.

## 달리기와 갈아타기 개선 확인

- 루미돈 몸통과 탑승자가 위아래로 들썩이고 다리가 크게 뻗는지 확인합니다. 카메라까지 위아래로 흔들리는 효과는 아닙니다. 타지 않은 무리에도 발밑 먼지가 나타납니다.
- 사냥터 장애물은 이끼 낀 바위와 쓰러진 통나무로 표시됩니다. 충돌 범위와 배치 빈도는 기존 시험값을 유지합니다.
- 스페이스바로 점프한 동안 A/D나 드래그로 좌우 이동하지 않습니다. 공중에서 스페이스바를 다시 눌러 줄을 던지는 조작은 유지합니다.
- 다른 몬스터로 갈아타 착지하면 0.6초 동안 1.5배로 앞으로 빨라지고 짧은 속도 궤적이 나타납니다. 첫 시작 탑승에는 적용하지 않습니다.
- 나중에는 여러 플레이어가 같은 사냥터를 사용하는 것을 목표로 합니다. 이번 검사는 1인 Play 기준입니다.

## 초원 1,000m 시험판 확인

- 작은·큰 이끼 바위와 초록 나무를 피합니다. 큰 장애물은 같은 종류의 2배 크기입니다.
- 앞길이 좁아졌다 두 갈래로 나뉩니다. A/D로 한쪽을 고르고 중앙의 풀 덮인 능선은 피하세요. 이후 다시 합쳐집니다.
- 갈아타기 직후 0.6초 대시 동안 주변 바람 고리와 긴 바람 자국이 보입니다. 첫 시작 탑승에는 대시를 하지 않습니다.
- 밝은 BGM, 주변 몬스터의 발굽 소리, 점프·줄·착지·포획 성공 소리를 확인합니다. Studio와 Windows의 볼륨도 켜주세요.
- 1,000m에서 주행이 멈추고 **다음 지역 준비 중** 안내가 유지됩니다. **사냥 시작**으로 초원을 다시 시험할 수 있습니다. 이후 테마는 아직 없습니다.

음원 로딩과 재생 상태를 자동 검사했습니다. 음악 취향·음량 균형·바람 연출의 실제 보기 좋은 정도는 직접 Play하면서 확인해야 합니다. 여러 플레이어가 함께 뛰는 시험은 아직 진행하지 않았습니다.

## 줄·먼지·상자·재시작 확인

- 공중에서 스페이스바를 다시 누르면 손에서 줄 고리가 앞으로 날아가고 잡는 대상이 잠깐 강조됩니다. 착지하면 큰 먼지와 바닥 원이 퍼졌다 사라집니다.
- 탑승 루미돈 뒤에는 풍성한 먼지가 남고 다른 달리는 몬스터도 적은 먼지를 냅니다.
- 대시 중 A/D로 방향을 바꿀 수 있습니다. 갈아타는 동안 누르고 있어도 착지 직후 반영됩니다.
- 달리는 속도는 그대로이며 미터 증가량은 이전의 3분의 1입니다. 대시 중에는 평상시보다 미터도 빨리 올라갑니다.
- 나무 상자를 만나면 루미돈으로 부술 수 있습니다. 나무 조각이 흩어지며 계속 달립니다. 아이템은 아직 정하지 않아 나오지 않습니다.
- 벽/바위/나무 충돌에는 탑승 몬스터도 함께 부서집니다. 가방 보유는 유지됩니다.
- 여러 번 다시 시작해도 앞쪽에 다음 몬스터가 있어야 합니다.

### Studio F5에서 내 아바타가 다를 때

계정 외형 로딩을 명시적으로 켰으며 StarterCharacter나 고정 외형을 넣지 않습니다. 그래도 다르면 다음을 확인하세요.

1. Shift+F5로 멈추고 새 배포 파일을 Ctrl+O로 엽니다.
2. Studio에 로그인한 계정이 원하는 아바타의 Roblox 계정인지 확인합니다.
3. **File → Avatar Settings** 또는 **Avatar 탭 → Avatar Settings**에서 외형 설정이 **Player Choice**인지 확인합니다. 이 설정은 개인 아바타를 바꾸지 않습니다.
4. **Window → Explorer**에서 **StarterPlayer**를 선택하고 **Window → Properties**에서 **LoadCharacterAppearance**가 켜져 있는지 확인합니다.
5. F5로 다시 실행하고 사냥 시작 전에도 외형이 같은지 확인합니다. 여전히 다르면 시작 전 모습과 Output의 아바타 관련 오류로 원인을 추가 확인해야 합니다.

근거: [Roblox 아바타 설정](https://create.roblox.com/docs/studio/avatar-settings), [StarterPlayer 외형 로딩](https://create.roblox.com/docs/reference/engine/classes/StarterPlayer). 현재 사용자 계정의 실제 F5 외형 일치 여부는 별도 확인 대상입니다.

## 로비 복귀와 새 표시 확인

1. 사냥 종료 또는 1,000m 도달 시 **로비로 돌아가기**를 누릅니다.
2. 로비에 도착하면 가방 마릿수와 모인 돈이 보이고 미터는 숨겨집니다. 다시 비행장에서 출발하면 가방·돈은 숨겨지고 미터만 표시됩니다.
3. 다시 사냥하기를 여러 번 사용하고 계속 달려도 화면 앞의 야생 몬스터가 최소 4마리 유지되는지 확인합니다. 좁은 길·갈림길에서도 확인하세요.
4. 상점은 외관만 있습니다. 목장에 넣기·배합·알 기능과 카페는 이번에 만들지 않았습니다.

## 공개 서버의 최대 인원 8명 설정

로컬 파일의 구역 배정은 8명으로 제한했지만 공개 서버 정원은 Roblox 웹 설정에도 지정해야 합니다. 아직 공개 경험의 ID를 정하지 않아 이 웹 설정은 대신 변경하지 않았습니다.

1. Studio에서 이 파일을 연 뒤 **File → Publish to Roblox**로 원하는 경험에 게시합니다. 기존 공개 게임에 적용할 때는 게시 대상을 먼저 확인합니다.
2. 브라우저에서 [Creator Dashboard](https://create.roblox.com/dashboard/creations)를 열고 해당 경험을 선택합니다.
3. **Configure → Places**에서 로비 장소를 선택하고 **Maximum Player Count / 최대 플레이어 수**를 **8**로 저장합니다. 화면 언어·업데이트에 따라 항목 이름은 다를 수 있습니다.
4. 다시 장소 설정을 열어 최대 인원이 8로 저장되었는지 확인합니다. 웹 정원 설정은 F5의 1인 시험으로 확인할 수 없습니다.

근거: [Roblox Players.MaxPlayers 문서](https://create.roblox.com/docs/reference/engine/classes/Players). 여러 클라이언트 동시 접속, 공개 서버 이동 및 영구 저장은 후속 검증입니다.
