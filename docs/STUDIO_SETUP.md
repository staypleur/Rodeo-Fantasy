# 루미돈 사냥터 테스트 적용

## 새 파일 열기

1. Roblox Studio에서 실행 중이면 **Stop / Shift+F5**를 누릅니다.
2. 이전 장소 탭을 닫습니다. 직접 편집한 내용은 **File → Save to File As**로 다른 이름에 먼저 저장하세요.
3. **File → Open from File / Ctrl+O**를 누릅니다.
4. 바탕 화면 **Project → Rodeo Fantasy → dist → RodeoFantasy-Capture.rbxlx**를 엽니다.
5. **Play / F5**로 실행합니다. 캐릭터 없이 실행하는 Run은 사용하지 않습니다.

## 조작과 성공 확인

1. **사냥 시작**을 누르면 첫 루미돈으로 날아가 탑승한 뒤 자동 전진합니다.
2. **A/D**로 좌우 이동합니다. 마우스를 누른 채 좌우로 끄는 조작도 지원합니다. 마우스를 떼어도 점프하지 않습니다.
3. **스페이스바를 한 번 누르면 점프**합니다. 공중에서 팔과 다리가 좌우로 벌어지고 노란 줄 범위가 나타납니다.
4. 원 안에 다음 몬스터가 들어오면 **스페이스바를 다시 누릅니다**. 줄이 연결되고 탑승합니다. 탑승하는 중 누른 키는 착지 후 새 점프로 예약되지 않습니다.
5. 타고 있는 몬스터의 화면 왼쪽 아래 **분홍색 원형 게이지와 하트**가 찹니다. 게이지가 가득 차면 가방 마릿수가 늘어나고 하트 게이지는 사라집니다. 같은 개체로 계속 달릴 수 있습니다. 달릴 때 하단 설명창은 숨깁니다.
6. 먼저 **느낌표(!)** 경고가 깜빡인 뒤 반복해서 뛰면서 좌우로 튕깁니다. 평소보다 방향 전환도 어려워집니다. 길들여진 루미돈도 똑같이 화나며, 화났다는 이유만으로 자동으로 떨어지지 않습니다. 계속 타거나 **스페이스바로 자발적으로 점프**해 갈아탈 수 있습니다.
7. 주행 중 다른 몬스터나 벽에 닿으면 즉시 종료됩니다. 플레이어 몸 부품이 흩어졌다 사라지며 **몬스터는 부서지지 않습니다**. **다시 사냥하기**를 누르면 플레이어가 다시 보이고 재도전합니다.
8. 기존 바위에 대한 착지 보호는 유지합니다. 보호가 끝나면 바위도 피해야 합니다. 몬스터와 벽 충돌에는 이 보호를 적용하지 않습니다.

터치는 화면의 **점프 / 줄** 버튼과 좌우 드래그로 대응합니다. 실제 기기 체감은 별도 확인이 필요합니다.

가방 보유와 수익은 이번 접속에서만 유지됩니다. 사냥 재시작은 유지하지만 **Stop 후 Play는 초기화**됩니다. 카페·영구 저장·합성과 진화는 아직 이 파일에 없습니다.

## 외형만 삽입

다른 장소의 **Explorer → Workspace 마우스 오른쪽 → Insert from File**에서 **dist/Lumidon.rbxmx**를 선택합니다. 외형 파일에는 사냥 코드가 없으므로 사냥 테스트는 장소 파일을 엽니다.

## 문제 확인

오류가 나오면 **Window → Output**을 열어 빨간 문장을 확인합니다. 자동 복구 저장 충돌이 생기면 새 이름으로 저장하고 Studio 창을 닫은 뒤 파일 하나만 다시 엽니다.

## 이번 화면 개선 확인

루미돈 몸통이 평상시에 빠르게 떨리지 않고 다리만 크게 뻗으며 달리는지 확인합니다. 화났을 때의 반복 점프와 좌우 튕김은 의도한 동작입니다. 분홍 게이지, 좌우로 뻗는 공중 팔다리, 충돌 부품 연출은 실제 Play에서 확인하세요.

## 앉는 자세와 주행 연출 확인

첫 탑승 뒤 다리를 앞으로 굽혀 앉고, 오른팔을 들어 머리 위에서 황금색 줄을 돌리는지 확인합니다. 점프하면 회전 줄이 사라지고 팔·다리를 펼치는 공중 자세로 바뀝니다. 착지 먼지, 지나가는 지면 바람 자국, 루미돈 귀·꼬리 움직임과 좌우 기울기도 확인하세요.

거리 1,000m, 2,000m 등에서 길 바닥선과 양쪽 표지판을 지나갑니다. 처음부터 1,000m 표지가 바로 앞에 있는 것은 아닙니다.
