# 앰버랫 탑승·포획 테스트 시작하기

## 1. 테스트 파일 열기

1. Roblox Studio를 실행합니다.
2. 상단 **File(파일) → Open from File(파일에서 열기)**를 누릅니다. Windows에서는 **Ctrl+O**로 파일 열기 창을 띄울 수도 있습니다.
3. 바탕 화면의 **Project → Rodeo Fantasy → dist** 폴더로 이동합니다.
4. **RodeoFantasy-Capture.rbxlx** 파일을 선택하고 엽니다.
5. 모래색 바닥과 앰버랫 이름표가 붙은 회색 블록이 들어 있는 테스트 장소가 열립니다.

GitHub에서 받는 경우 `dist/RodeoFantasy-Capture.rbxlx` 파일 페이지의 **Download raw file** 버튼으로 다운로드하세요. 웹페이지 자체를 저장하면 안 됩니다.

## 2. 캐릭터로 실행하기

1. 상단의 **Play(재생, 삼각형 버튼)**를 누르거나 **F5**를 누릅니다. 캐릭터 없이 실행하는 Run 모드는 사용하지 마세요.
2. 캐릭터가 나타나면 게임 화면 안을 한 번 클릭합니다.
3. 화면 아래에 **3m 안의 앰버랫 블록을 클릭하세요**라는 안내가 보이는지 확인합니다.
4. **W/A/S/D**로 회색 블록에 가까이 갑니다. 블록 위에 마우스를 올리면 거리가 표시됩니다.
5. **3m 안**에서 블록을 클릭합니다. 줄이 연결되고 캐릭터가 점프해 올라갑니다.
6. 탑승 후에는 자동으로 앞으로 갑니다. **A는 왼쪽, D는 오른쪽**입니다.
7. 탑승 후 3초가 지나면 화면 아래에 판정 막대가 나타납니다.

## 3. 포획하기

막대가 원하는 구역에 왔을 때 **스페이스바를 한 번** 누릅니다.

| 판정 | 결과 |
| --- | --- |
| 흰색 | 즉시 떨어집니다. 같은 블록에 가까이 가서 다시 클릭하면 재도전합니다. |
| 노란색 | 5초 동안 추가 입력 없이 타고 있으면 포획합니다. A/D 이동은 계속 가능합니다. |
| 주황색 | 즉시 포획합니다. |

처음에는 흰색 85% / 노란색 14% / 주황색 1%입니다. 같은 테스트 실행에서 앰버랫을 한 번 포획하면 다음 시도는 80% / 17% / 3%가 됩니다.

성공하면 **포획 성공!** 문구와 **이번 접속 포획: 1마리**가 표시됩니다. 반복 테스트를 위해 그 자리에 1초 후 새 블록이 나타납니다. 이 재생성 방식은 테스트 장치이며 정식 게임의 생성 규칙은 아닙니다.

## 4. 테스트 끝내기

- 상단 **Stop(정지, 사각형 버튼)** 또는 **Shift+F5**를 누릅니다.
- 다시 Play를 누르면 처음부터 시작하며 포획 수는 0으로 초기화됩니다.
- 직접 편집한 파일을 보관할 때는 **File → Save to File As**로 별도 이름을 사용하세요. 배포 파일은 다음 코드 업데이트 때 다시 생성됩니다.

## 이번 버전에서 확인할 것

- 회색 블록은 외형이 정해지기 전 기능 확인용입니다. 앰버랫의 최종 모습이 아닙니다.
- 맵은 탑승 테스트용 평지입니다. 이동에 따라 바닥이 이어지며, 정식 황무지 지역이나 보스는 아직 없습니다.
- 포획 수는 현재 접속에서만 유지됩니다. 게임을 종료하고 다시 들어올 때 저장되는 기능은 이후 단계입니다.
- 근접형, 불/포유류, 기력 40, 불꽃 이빨 정보는 코드에 저장되어 있지만 전투는 아직 실행되지 않습니다.
- PC 마우스·키보드 조작 버전입니다.

## 문제가 생기면

- 캐릭터가 없으면 Stop을 누르고 **Play(F5)**로 다시 실행하세요.
- 클릭해도 안 타지면 블록에 더 가까이 가고, 화면 아래 안내를 확인하세요.
- 오류가 뜨면 **Window → Output(출력)**을 열고 빨간 오류 문장을 복사해서 보내주세요. 메뉴 위치가 다르면 보이는 화면을 보내주셔도 됩니다.
- 화면에서 누른 색과 결과가 다르면 알려주세요. 현재 서버에 입력이 도착한 시각으로 판정하므로 온라인 지연 보정은 실제 플레이 확인 후 조정해야 합니다.
