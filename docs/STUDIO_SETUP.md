# Roblox Studio 적용과 확인

현재 파일에는 새 초원5종 1성의 주행과 A안 단계별 부품 근사 모델이 들어 있습니다. GLB MeshPart 설치가 끝나기 전에는 승인 그림에 가까운 완성 3D 모델이 표시되지 않습니다. 합성 기능은 미정이므로 사냥 중 자동 진화하지 않습니다.

## 새 파일 실행

1. Roblox Studio에서 시험 중이면 **Shift+F5**로 멈춥니다.
2. **File → Open from File** 또는 **Ctrl+O**를 누릅니다.
3. 프로젝트 폴더의 **dist → RodeoFantasy-Capture.rbxlx**를 선택합니다. 이전 열린 파일을 그대로 시험하면 변경이 보이지 않습니다.
4. **File → Save to File As**로 새 이름에 저장하면 자동 복구 파일 잠금 충돌을 피할 수 있습니다.
5. **F5**로 실행합니다. 중앙 평지에 나타나는지 확인하세요. A 디자인 MeshPart를 넣으려면 [20개 모델을 가져와 설치하는 절차](ROBLOX_MODEL_IMPORT.md)를 완료해야 합니다. 그냥 F5만 누르면 기존 부품 근사 모델이 보입니다.

## 로비

- 기본 목장은 내 구역 4개. 높은 간판에 내 계정 이름이 표시됩니다. 다른 구역에는 관리 E가 보이지 않아야 합니다.
- 내 구역 입구 가까이에서 **E 1초** → 1~4번 목장 선택 → 원하는 가방 개체 **Place/배치**. 최대2마리, 회수는 **Return to bag/가방으로 돌려놓기**. 배치된 개체는 안에서 걷고 먼지가 없어야 합니다.
- **R 키** 또는 가방 버튼 → 3D 몬스터 이미지·별·생산량. 가방 그림은 갈색, 돈은 금화 그림으로 표시됩니다.
- 중앙의 **사다리**에 걸어 붙어 **W**로 올라갑니다. 열린 바구니 입구에서 **E를 1초** 누르면 사냥 시작. 가까이만 가서는 출발하지 않습니다.
- 분수/계단/돌출 원형 발판은 없으며 벤치·화단·상점·게시판은 길 사이에 원형 배치되어 통로가 열려 있어야 합니다.
- 로비 음악과 사냥 음악은 다릅니다. 상점은 외관이며 판매 기능은 아직 없습니다.

## 사냥

**A/D** 좌우, **Space** 점프, 공중에서 다시 **Space**로 줄. 공중 조향 불가, 대시 중 조향 가능. 종별5~7초 길들이기 후 하트 숨김, 이후 느낌표/화남 점프에도 계속 탑승 가능. 사망 후 **Space로 재도전**, **E 1초로 로비 복귀** 또는 두 버튼을 마우스로 즉시 누릅니다.

주변 야생은 내 탑승 개체 제외4~6마리. 표시 대상이 매 프레임 바뀌어 깜빡이지 않고 화면을 벗어난 개체를 보충해야 합니다. 잡초까마귀는 현재 지상 장애물/지상 몬스터를 넘지만 높은 협곡 벽과 다른 비행형은 피해야 합니다. 1,000m에서 멈추고 다음 지역 준비 중 안내가 나옵니다.

현 시험 몬스터의 외형/수익은 신규 목록 교체 전입니다. **꼬마쥐·풀멧돼지·나무늑대강아지·바위코끼리 신규 행동과 3/6/9성 모델은 시안 선택 후 적용합니다.**

## 랭킹 저장 시험

게시판은 게임 전체 최장거리/누적 생산액 상위10명, 약60초마다 갱신합니다. **가방과 사용 가능한 돈의 영구 저장과는 별개**이며 현재 가방은 Stop 후 Play하면 초기화됩니다.

1. 별도 시험 경험에 **File → Publish to Roblox**로 게시합니다. 실제 공개 게임을 덮어쓰지 않도록 대상을 확인하세요.
2. **File → Experience Settings → Security → Enable Studio Access to API Services**를 켜고 **Save**. Studio 메뉴 버전에 따라 Game Settings로 보일 수 있습니다.
3. F5로 사냥/포획하고 생산액을 얻은 뒤60초 기다립니다. 게시판 기록을 확인하고 Shift+F5 후 다시 실행해 기록이 남는지 확인합니다.
4. Studio 시험 저장소 이름은 `_Test_v1`, 공개 Roblox 서버는 `_v1`이어서 시험 기록이 공개 순위를 오염시키지 않습니다.
5. 게시하지 않은 파일은 ‘Publish to enable rankings’, 저장 API 오류는 기록 이용 불가 메시지/Output 경고를 표시합니다. 실패를 성공이라고 표시하지 않습니다.

근거: [Roblox DataStore 공식 안내](https://create.roblox.com/docs/cloud-services/data-stores). 실제 공개 저장/재접속은 아직 대신 검증하지 못했습니다.

## 서버 정원과 언어

[Creator Dashboard](https://create.roblox.com/dashboard/creations)에서 해당 경험 → Configure → Places → 로비 장소의 **Maximum Player Count=8** 저장. 파일의 구역 배정은8명으로 제한하지만 공개 서버 웹 정원도 필요합니다.

영어 기본, 한국어/일본어 계정 언어에 맞춰 표시합니다. 이름은 번역하지 않습니다. 다른 언어는 게시한 경험의 번역 표/자동 번역 설정이 필요합니다.

오류는 **Window → Output**의 빨간 문장으로 확인하세요. 내 아바타가 다르면 Studio 로그인 계정, **Avatar Settings → Player Choice**, **StarterPlayer → LoadCharacterAppearance**를 확인합니다. 고정 StarterCharacter는 사용하지 않습니다.

## 새 몬스터 확인

- 시작: 꼬마쥐,150m부터 풀멧돼지,300m부터 나무늑대강아지,400m부터 잡초까마귀,500m부터 바위코끼리. 준비 무리 때문에 경계 앞에서 보일 수 있습니다.
- 풀멧돼지/나무늑대강아지: 갈아탄 직후 대시로 야생 소·중형을 날립니다. 대형과 충돌하면 종료됩니다.
- 바위코끼리: 대시가 없어도 야생 소·중형과 작은 나무·바위를 부숩니다. 작은 장애물은5초 뒤 복구됩니다. 대형끼리 충돌하면 종료됩니다.
- 나무늑대강아지가 화나면 연속3번 점프하고 잠깐 착지한 뒤 반복합니다.
- 성장 외형을 따로 보려면 **Shift+F5**로 멈추고 Explorer에서 **ServerStorage**의 이름 뒤 `_S3`, `_S6`, `_S9` 모델을 선택합니다. **Ctrl+C**, Explorer의 **Workspace**를 선택하고 **Ctrl+V** 하면 화면에 미리 놓아볼 수 있습니다. 이 사본은 배포하지 않는 별도 시험 파일에서 확인하고 지우세요. 자동 합성 기능은 아직 없습니다.
- 나무 사다리가 보이고 중앙에 등장해야 합니다. 사다리에는 투명한 기본 등반 판정과 보이는 나무 기둥/발판이 있습니다.

## 도감·가방·몸집 변경 확인

1. 기존 시험을 Shift+F5로 멈춥니다. Studio에서 Ctrl+O → 프로젝트의 dist/RodeoFantasy-Capture.rbxlx 선택 → 열기 → F5.
2. 중앙 평지에서 등장하는지, 로비가 블록/스터드 형식인지 봅니다. 캐릭터 이름 옆의 청록 잎 레벨을 확인합니다.
3. 로비에서 T를1초 누릅니다. 책이 열리면 W/Space로 캐릭터가 움직이지 않아야 합니다. A/D 또는 아래 화살표로 페이지를 바꿉니다. 페이지 번호와 카드 위 획득 말풍선을 확인합니다. 오른쪽 위 × 버튼을 클릭해 닫고 다시 움직일 수 있어야 합니다.
4. 사다리를 올라 바구니에서 E를1초 눌러 사냥합니다. 몬스터의 어두운 윤곽선, 청록 줄 범위를 확인합니다. 중앙에 갑자기 나타나는 개체 없이 주변 야생4~6마리가 보충되는지 봅니다.
5. 150/300m 중형과500m 바위코끼리의 몸집을 소형과 비교합니다. 대형에 탄 플레이어가 작아 보이고 안장에 자연스럽게 앉는지 확인합니다.
6. 몬스터를 길들여 로비로 돌아온 뒤 R을 눌러 이름 검색/지역 탭을 사용합니다. 실제3초 생산 시 해당 카드에 금화/+금액이 뜨는지, 목장 배치 시 몬스터 위에도 표시되는지 확인합니다. T 도감에서 잡은 몬스터가 실루엣 대신 정상 모델/이름으로 표시되어야 합니다.

도감/경험치 영구 저장은 게시된 경험의 API 사용 설정과 실제 재접속 시험이 필요합니다. 미게시 파일은 세션 기록이며 가방/잔액은 아직 영구 저장하지 않습니다. 실제8클라이언트/모바일 성능은 이번 편집 모드 검사의 범위 밖입니다.

## A 모델 가져오기와 게시

최신 장소 파일에는 청록 지붕·석조 정원 A안 로비가 들어 있습니다. 다만 GLB는 자동 삽입되지 않으며 기존 부품 근사 모델이 보입니다. 승인된 20개 3D 모델을 가져와 연결하고 사냥·목장·가방·도감에서 확인하려면 [Studio 모델 가져오기 절차](ROBLOX_MODEL_IMPORT.md)를 완료하세요. Roblox에서 다른 플레이어에게 로비 변경을 보여주려면 마지막에 **File → Publish to Roblox**가 필요합니다. Git 커밋/푸시는 Roblox 게시가 아닙니다.

현재 저장소에는 승인된 A 디자인을 바탕으로 만든 20개 로우폴리 3D GLB가 `dist/CreatureModels`에 있습니다. 기존 장소 파일에는 로비 A 건축이 들어 있지만 GLB는 장소에 자동 삽입되지 않습니다. 게임 템플릿에 실제 메시를 넣는 데 필요한 Studio 가져오기와 연결 스크립트는 [ROBLOX_MODEL_IMPORT.md](ROBLOX_MODEL_IMPORT.md)를 따르세요.

가져온 정적 `MeshPart`는 런타임 EditableMesh 권한에 의존하지 않습니다. 반대로 아직 수동 가져오기를 하지 않은 템플릿은 기본 부품 모델을 사용하고, 런타임 변형 메시가 실패하면 Studio **View → Output**에 `Creature mesh unavailable` 원인을 남깁니다. EditableMesh 공개 권한은 [Roblox 공식 안내](https://create.roblox.com/docs/reference/engine/classes/EditableMesh)를 확인하세요.
