# Roblox Studio 적용과 확인

현재 파일에는 로비 개선과 교체 전 루미돈/잡초까마귀 주행 시험이 들어 있습니다. 새 초원 5종·진화형은 디자인 선택 후 적용합니다. 기획과 실제 적용 범위를 구분하세요.

## 새 파일 실행

1. Roblox Studio에서 시험 중이면 **Shift+F5**로 멈춥니다.
2. **File → Open from File** 또는 **Ctrl+O**를 누릅니다.
3. 프로젝트 폴더의 **dist → RodeoFantasy-Capture.rbxlx**를 선택합니다. 이전 열린 파일을 그대로 시험하면 변경이 보이지 않습니다.
4. **File → Save to File As**로 새 이름에 저장하면 자동 복구 파일 잠금 충돌을 피할 수 있습니다.
5. **F5**로 실행합니다. 중앙 평지에 나타나는지 확인하세요.

## 로비

- 기본 목장은 내 구역 4개. 높은 간판에 내 계정 이름이 표시됩니다. 다른 구역에는 관리 E가 보이지 않아야 합니다.
- 내 구역 입구 가까이에서 **E 1초** → 1~4번 목장 선택 → 원하는 가방 개체 **Place/배치**. 최대2마리, 회수는 **Return to bag/가방으로 돌려놓기**. 배치된 개체는 안에서 걷고 먼지가 없어야 합니다.
- **R 키** 또는 가방 버튼 → 3D 몬스터 이미지·별·생산량. 가방 그림은 갈색, 돈은 금화 그림으로 표시됩니다.
- 중앙의 **사다리**에 걸어 붙어 **W**로 올라갑니다. 열린 바구니 입구에서 **E를 1초** 누르면 사냥 시작. 가까이만 가서는 출발하지 않습니다.
- 분수/계단/돌출 원형 발판은 없으며 벤치·화단·상점·게시판은 길 사이에 원형 배치되어 통로가 열려 있어야 합니다.
- 로비 음악과 사냥 음악은 다릅니다. 상점은 외관이며 판매 기능은 아직 없습니다.

## 사냥

**A/D** 좌우, **Space** 점프, 공중에서 다시 **Space**로 줄. 공중 조향 불가, 대시 중 조향 가능. 5초 길들이기 후 하트 숨김, 이후 느낌표/화남 점프에도 계속 탑승 가능. 사망 후 **Space로 재도전**, **E 1초로 로비 복귀** 또는 두 버튼을 마우스로 즉시 누릅니다.

주변 야생은 내 탑승 개체 제외4~6마리. 표시 대상이 매 프레임 바뀌어 깜빡이지 않고 화면을 벗어난 개체를 보충해야 합니다. 잡초까마귀는 현재 지상 장애물/지상 몬스터를 넘지만 높은 협곡 벽과 다른 비행형은 피해야 합니다. 1,000m에서 멈추고 다음 지역 준비 중 안내가 나옵니다.

현 시험 몬스터의 외형/수익은 신규 목록 교체 전입니다. **꼬마쥐·풀멧돼지·나무늑대강아지·바위코끼리 신규 행동과 3/6/9성 모델은 시안 선택 후 적용합니다.**

## 랭킹 저장 시험

게시판은 게임 전체 최장거리/누적 생산액 상위10명, 약60초마다 갱신합니다. **가방과 사용 가능한 돈의 영구 저장과는 별개**이며 현재 가방은 Stop 후 Play하면 초기화됩니다.

1. 별도 시험 경험에 **File → Publish to Roblox**로 게시합니다. 실제 공개 게임을 덮어쓰지 않도록 대상을 확인하세요.
2. **File → Experience Settings → Security → Enable Studio Access to API Services**를 켜고 **Save**. Studio 메뉴 버전에 따라 Game Settings로 보일 수 있습니다.
3. F5로 사냥/포획하고 생산액을 얻은 뒤60초 기다립니다. 게시판 기록을 확인하고 Shift+F5 후 다시 실행해 기록이 남는지 확인합니다.
4. Studio 시험 저장소 이름은 `_Test_v1`, 공개 Roblox 서버는 `_v1`이어서 시험 기록이 공개 순위를 오염시키지 않습니다.
5. 게시하지 않은 파일은 ‘Publish to enable rankings’, 저장 API 오류는 기록 이용 불가 메시지/Output 경고를 표시합니다. 실패를 성공이라고 표시하지 않습니다.

근거: [Roblox DataStore 공식 안내](https://create.roblox.com/docs/cloud-services/data-stores). 실제 공개 저장/재접속은 아직 대신 검증하지 못했습니다.

## 서버 정원과 언어

[Creator Dashboard](https://create.roblox.com/dashboard/creations)에서 해당 경험 → Configure → Places → 로비 장소의 **Maximum Player Count=8** 저장. 파일의 구역 배정은8명으로 제한하지만 공개 서버 웹 정원도 필요합니다.

영어 기본, 한국어/일본어 계정 언어에 맞춰 표시합니다. 이름은 번역하지 않습니다. 다른 언어는 게시한 경험의 번역 표/자동 번역 설정이 필요합니다.

오류는 **Window → Output**의 빨간 문장으로 확인하세요. 내 아바타가 다르면 Studio 로그인 계정, **Avatar Settings → Player Choice**, **StarterPlayer → LoadCharacterAppearance**를 확인합니다. 고정 StarterCharacter는 사용하지 않습니다.
