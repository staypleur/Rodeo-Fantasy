# 초원 5종 교배 조합 검토 초안

확정 결과표가 아니다. 게임에 적용하지 않는다. 사용자 요청에 따라 고래·도감을 먼저 완성한다. 교배/부화 시간은 사용자가 나중에 지정한다. 이전에 제안한 시간표는 승인되지 않았다.

확정된 방식: 서로 다른 종류도 가능하며 목장의 수컷·암컷 두 마리가 일정 시간 후 알을 낳는다. 알은 별도 부화 시간이 지나면 가까이에서 E를 길게 눌러 새 몬스터를 받는다. 새 포획 개체의 성별은 각각 50%다. 부모의 별과 조합이 결과에 영향을 주지만 최종 결과·별 공식·확률은 미정이다.

아래는 **외형 방향만 제안**하는 15개 조합이다. 새 이름과 모델, 능력은 각각 사용자 확인이 필요하다. 성별에 따른 부모 순서 효과도 미정이다.

| 부모 조합 | 결과 외형 방향 제안 |
|---|---|
| 모스랫 × 모스랫 | 모스랫 정체성 유지, 별에 따른 성장 검토 |
| 브램블보어 × 브램블보어 | 브램블보어 정체성 유지, 별에 따른 성장 검토 |
| 바인팽 × 바인팽 | 바인팽 정체성 유지, 별에 따른 성장 검토 |
| 쏜크로 × 쏜크로 | 쏜크로 정체성 유지, 별에 따른 성장 검토 |
| 엘레바인 × 엘레바인 | 엘레바인 정체성 유지, 별에 따른 성장 검토 |
| 모스랫 × 브램블보어 | 큰 귀와 풀 갈기를 가진 작은 튼튼한 체형 |
| 모스랫 × 바인팽 | 클로버와 나뭇잎을 가진 민첩한 체형 |
| 모스랫 × 쏜크로 | 큰 귀와 잎 날개를 가진 작은 비행 체형 |
| 모스랫 × 엘레바인 | 작은 새싹과 돌 장식을 가진 둥근 발 체형 |
| 브램블보어 × 바인팽 | 풀 갈기와 나무 갑옷을 가진 달리기 체형 |
| 브램블보어 × 쏜크로 | 넓은 풀 날개와 튼튼한 몸의 체형 |
| 브램블보어 × 엘레바인 | 이끼 낀 돌 갑옷과 풀 갈기를 가진 큰 체형 |
| 바인팽 × 쏜크로 | 나뭇잎 날개와 긴 꼬리를 가진 체형 |
| 바인팽 × 엘레바인 | 나무·돌 장식을 가진 길쭉한 대형 체형 |
| 쏜크로 × 엘레바인 | 돌판과 넓은 잎 날개를 가진 묵직한 비행 체형 |

별 결과는 별도 조합표가 필요하다. 예를 들어 1성×9성이나 3성×6성의 결과를 임의로 정하지 않는다. 새 결과종을 만들지 않고 기존 부모종으로 나오는 방식도 선택 가능하다. 목장 반복 생산, 알 개수 제한, 부모 소모 여부, 오프라인 시간 진행, 진화 후 성별도 미정이다.
