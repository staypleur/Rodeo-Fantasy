# 작업 기록

## 2026-10-08 — 연속 탑승 흐름과 원작 구도/속도 보완

- 사용자 피드백: 첫 몬스터로 날아가 탑승 후 계속 타다가 일정 시간이 지나 느낌표와 화남이 나타나는 흐름을 요청했다. 계속 갈아타야 하는 것처럼 느껴지는 동작과 낮거나 다른 시점/속도 체감을 수정한다.
- 탑승 중 버튼을 뗐을 때 착지 직후 자동 재점프하는 코드를 제거했다. 빠른 클릭의 누르기/떼기 중 하나를 버리는 Hold 시간 제한도 제거했으며 공중 누르기는 즉시 줄 후보를 판정한다.
- 시작을 첫 몬스터로 날아가 탑승하는 연출로 연결했다. 길들이기 완료 안내를 계속 탈 수 있다는 내용으로 고쳤다. 화나면 머리 위 느낌표가 나타나며 경고를 이전 안내 문장이 가리지 않는다.
- 카메라는 길 중심을 따라가면서 옆에서 내려다보고, 좌우 이동은 화면에서 보이도록 수정했다. 주행 속도 40→64 studs/s, 무리 24→44, 공중 60→80으로 조정했다.
- 두 번째 영상의 약 8.825초/2464m와 15.192초/2720m에서 표시 속도 약 40.2m/s를 관찰했다. 표시 계수 0.625로 시험 주행 약 40m/s를 맞춘다. 계수는 실제 미터 변환이 아니며 영상 전체의 동일 속도를 보장하지 않는다.
- 카메라 오프셋과 화면 체감은 영상 기준의 시험 조정이며 원작과 완전히 동일하다고 주장하지 않는다.
- 이번 변경: 컨트롤러 회귀 검사 25개 통과. 빠른 누르기/떼기, 시작 비행, 착지 뒤 연속 탑승, 길들이기 뒤 주행 유지, 화남 속성과 종료를 포함한다. 배포 XML/참조/7개 소스 일치 검사와 Luau 파일 12개 컴파일, 변경 공백 검사 통과.
- 추가 실제 Play 검사는 새 검사용 Studio가 로그인 창에서 멈춰 실행 결과를 받지 못했다. 이번 변경의 Play 통과로 기록하지 않는다. 새 검사 세션과 이전에 남아 있던 제가 연 검사 세션만 식별해 종료했다. 사용자의 Studio 창은 종료하지 않았다. 느낌표 표시와 사선 카메라의 실제 화면 체감은 수동 확인이 남아 있다.

## 2026-10-08 — 카페/사냥터 기획 재정리와 루미돈 전환

### 사용자 확정

- 공간은 카페와 사냥터 두 곳이다. 카페에서는 보유 몬스터를 꺼내 동행/탑승하고 음성으로 소통한다. 사냥터에서는 Rodeo Stampede 방식으로 몬스터를 포획한다. 우선 사냥터를 제작한다.
- 보유 개체는 소환 없이도 각자 일정 간격과 금액으로 돈을 생산한다. 구매할 물품은 추후 사용자 결정이다.
- 같은 종류·같은 별 3마리로 다음 별 등급 1마리를 만든다. 최대 10성, 3/6/9성에서 모습과 생산량이 증가하는 진화를 한다.
- 외부 캐릭터 콘텐츠를 폐기하고 독자적인 디자인/이름으로 제작한다. 질문 답변으로 첫 몬스터는 등불을 단 블록 아기멧돼지 **루미돈**으로 확정했다.

### 변경

- 기획, README, 적용 안내, 모델 안내, 참고 조사와 검증 기록을 현재 기획 중심으로 다시 작성했다. 이전 모델 생성기·모델 파일·미리보기와 현재 소스의 이름/참조를 교체했다.
- 루미돈을 46개 기본 블록 부품과 PointLight로 제작했다. 앞/뒤 네 다리 달리기와 원점 유지를 연결했다. 미리보기는 실제 모델 부품을 투영한 그림이며 Studio 스크린샷은 아니다.
- 공식 안내와 사용자 영상을 재조사했다. 누르기/점프/줄/갈아타기/길들이기를 유지하고 빠져 있던 착지 보호를 추가했다. 시험 보호 시간은 2초이며 원작의 정확한 수치로 주장하지 않는다.
- 공중 줄 후보 표시에서 직전에 탄 개체를 제외해 서버의 잡기 조건과 맞췄다. 포획 지급과 충돌 판정은 서버가 처리한다.
- 높은 카메라와 점프 시 지면 기준 추적을 유지한다.
- 현재 작업 파일과 기록을 정리하며 Git의 과거 커밋 자체는 다시 쓰지 않는다. 과거 검증 결과를 새 모델/새 코드의 결과로 가져오지 않는다.

### 이번 변경 검증

- 장소와 단독 모델을 다시 생성했다. XML 구조/참조/7개 내장 소스의 원본 일치 검사 통과.
- 소스와 Luau 검사 파일 컴파일 통과. 순수 사냥 계산 20개와 가방 계산 15개 통과.
- 실제 Studio 모델/월드 검사 통과: 루미돈의 돌기·등불·네 다리 동작·원점 유지, 달리는 무리, 줄 후보, 장애물과 먼 개체 정리.
- 실제 컨트롤러를 Studio 모델과 제어된 입력/시간으로 검사해 21개 통과. 착지 보호가 충돌을 막고 만료되는 것을 포함한다.
- 첫 실제 Play 검사에서 클라이언트의 RideAnimator가 아직 복제되지 않아 UI 생성 전에 실패했다. 필요한 모듈·월드 부품을 WaitForChild로 기다리도록 고쳤다.
- 수정 후 실제 Play 12개 검사 통과: UI 생성, 높은 카메라와 시야각, 시작/점프/줄/탑승, 착지 보호, 길들이기 지급/중복 방지, 종료 시 이동·시야각 복원, 재시작 보유 유지와 화남 종료. 테스트는 실제 서버/클라이언트 RemoteEvent를 사용하지만 마우스/터치 실물 조작이나 화면의 미술 체감 검사는 아니다.
- 검사에 사용한 별도 Studio 세션은 모두 종료됐다. 변경사항 공백 검사와 현재 파일의 폐기된 캐릭터 이름/참조 검색 통과.

### 미완료

- 실제 화면과 입력의 원작 대비 체감, 터치 기기, 다중 플레이어 검증.
- 카페 Place와 공간 이동, 영구 저장, 몬스터별 최종 수익표, 소환/동행/카페 탑승, 음성 채팅 설정, 합성/진화와 물품 구매.
- 현재 단일 사냥터 시험 파일을 두 공간이 연결된 완성판이라고 취급하지 않는다.
