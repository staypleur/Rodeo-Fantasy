## 2026-10-09 — 검토용 로비·몬스터 시안과 이름표 동작

- 사용자는 로비·몬스터 등 시각 디자인은 게임에 적용하기 전에 반드시 시안으로 확인하고 승인하기로 재확인했다. A안 로비와 승인 A 꼬마쥐의 검토용 3D 콘셉트 이미지를 만들고, 짧은 로비 이름표 및 진화 화면의 레이아웃 초안을 `assets/previews`에 저장했다. 콘셉트 렌더는 실제 Roblox MeshPart가 아니며, 어떤 시안도 Roblox 장소에 적용하지 않았다.
- 사용자가 진화 조건을 확정: 같은 종류·같은 별 3마리를 사용자가 가방에서 선택해 진화한다. 자동 진화는 하지 않는다. 합성/진화 기능과 화면은 아직 구현 전이며, UI 시안을 승인받기 전에는 가방 화면을 바꾸지 않는다.
- 이름표 스크립트는 자신의 레벨/이름 Billboard를 사냥 중 숨기지 않고 다른 플레이어의 것만 숨기고 있었다. 사냥 중 자신의 전체 이름표를 숨기고 로비 복귀 시 원래 상태로 복구하는 동작을 추가했다.
- 추가한 `tests/studio_hunt_nameplate.luau`는 사냥 진입/복귀와 사냥 중 늦게 생성된 이름표까지 확인한다. 이 검사는 Roblox Studio 안에서 실행해야 하므로, 이번 로컬 검사 통과를 실제 F5 확인으로 간주하지 않는다.
- 미완료: 짧은 로비 이름표와 진화 UI 시안 승인, 로비/몬스터 실제 Roblox 3D 품질, 진화 시스템. 로비·꼬마쥐 이미지는 참고 시안일 뿐이며, 사용자가 승인한 뒤 별도 구현/검증한다.

## 2026-10-08 — 탑승 떨림 수정과 사냥터 화면/동작 개선

- 사용자 피드백: 탑승 중 덜덜거림, 밋밋한 화면, 더 비스듬한 카메라, 구별되는 비행 자세와 역동적인 몬스터 달리기를 요청했다.
- 질문 답변으로 밝은 초원·층진 협곡·작은 먼지 효과·간결한 UI 방향을 확정하고 기획에 반영했다. 몬스터 종류와 포획/수익 규칙은 이번 미술 작업에서 새로 확정하지 않았다.

- 캐릭터와 카메라는 표시용 탑승 위치를 함께 따른다. 평상시 몸통의 빠른 상하 진동은 없애고 네 다리의 대각선 보폭/발 들어올리기를 확대했다. 무리의 발걸음 시작 위상도 분산했다. 화남 때의 의도적인 날뛰기는 유지한다.
- 공중에서는 상체를 앞으로 기울이고 팔다리를 벌린다. 탑승 자세로 돌아오며 종료/캐릭터 교체 때 관절과 기본 Animate 상태를 복원한다. 짧은 공중 궤적, 지면 그림자와 착지 후 발 뒤의 작은 먼지를 추가했다. 효과는 로컬에서 생성/정리하고 서버 판정에 참여하지 않는다.
- 카메라를 약 47도 사선으로 조정했다. 실제 Play 초기 구도 검사에서 발견한 추가 카메라 추적 지연을 제거했다. 화면 표현은 기본 카메라보다 뒤의 명시적인 렌더 순서에서 적용하고, 이미 보간된 표시 위치를 카메라가 바로 따라간다.
- 초원, 겹친 협곡 지층/풀 덮개, 가장자리 풀과 나무를 추가하고 UI를 축소했다. 배경 장식은 CanCollide/CanTouch/CanQuery가 모두 꺼져 있다. 바위 충돌 크기와 기존 생성 확률은 유지했다. 사냥 무리의 반복 이름표를 숨겼다.
- 검증: 최종 XML/참조/8개 내장 소스 일치와 단독 모델 검사, Luau 13개 파일 컴파일, 사냥 계산 20개와 가방 계산 15개, 변경 공백 검사 통과.

- 장애물에 끼어 멈추는 무리를 고치고, 몸통도 들썩이며 달리게 한다. 타지 않은 몬스터에도 먼지를 추가한다.
- 장애물을 초원·협곡 배경에 맞는 나무/바위 형태로 꾸민다.
- 추가 영상 참고: https://www.youtube.com/shorts/8bzDabyoXoo
- 공중에서는 좌우로 조작하지 않는다. 다른 몬스터로 갈아탄 직후 잠깐 가속한다. 질문에서 0.6초 동안 1.5배를 선택했다.
- 사냥터는 앞으로 여러 플레이어가 함께 사용하는 공간이다. 현재 개발 검사는 1인 기준이며 동시 접속·플레이어 간 규칙은 후속 범위다.

### 변경과 원인

- 기존 회피 코드가 처음부터 장애물과 겹친 위치에서 모든 이동을 막았다. 겹친 장애물에서는 빈 통로 쪽으로 가로 탈출을 허용하고 전진을 재개한다. 새 장애물로 관통하는 동작은 계속 막는다.
- 몸통에 한 걸음 주기의 위아래 움직임과 앞뒤 기울기를 추가하고 다리 진폭도 키웠다. 탑승자가 같은 표시 좌표를 따라 움직이며 카메라 높이와 서버 충돌 좌표는 유지한다.
- 가까운 무리의 발밑 먼지를 추가했다. 전체 먼지 개수와 수명을 제한하고 먼 몬스터는 기존 표시 거리로 제외한다.
- 기존 장애물 충돌 부품 안에 이끼 바위·돌조각 또는 쓰러진 통나무·밝은 단면·부러진 가지 장식을 넣었다. 배치 확률·충돌 크기는 유지한다. 외형 장식은 충돌과 줄 판정을 만들지 않는다.
- 공중 A/D·드래그는 클라이언트와 서버에서 무시한다. 공중 스페이스바 줄 던지기는 유지한다.
- 갈아타기 착지에만 서버가 0.6초/1.5배 전진 가속을 부여한다. 클라이언트 예측과 거리 표시는 같은 가속 시간을 사용하고 짧은 속도 궤적을 표시한다. 첫 탑승과 점프 후에는 갈아타기 가속을 유지하지 않는다.
- 탑승 이동이 캐릭터의 앞쪽 안장 오프셋을 매 틱 더하고 있었던 문제도 수정했다. 몬스터 기준 좌표에서 이동해 정해진 속도와 거리 계산이 일치한다.
- 영상은 브라우저에서 재생/장면 확인했다. 입력 제한은 사용자 설명, 가속 수치는 사용자 답을 근거로 한다. 영상만으로 원작의 정확한 가속 배율·시간을 측정했다고 주장하지 않는다.
