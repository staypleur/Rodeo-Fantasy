## 2026-10-08 — 화남 조종/원형 게이지/스페이스바/충돌 연출

- 사용자 확정: 화난 몬스터가 반복 점프하며 플레이어를 털어내려 하고 조종도 어려워진다. 진행 표시는 첨부 이미지처럼 몬스터 위의 원형 게이지를 사용한다. 주행 중 몬스터·벽 접촉은 낙하/종료로 이어진다. 공중 팔다리는 좌우로 뻗는다.
- 질문 답변: 산산조각 연출의 대상은 플레이어만이며 몬스터는 부서지지 않는다. PC는 스페이스바로 점프하고 공중에서 다시 스페이스바로 줄을 던진다. 기획과 적용 안내를 새 조작으로 수정했다.
- 사용자 영상 J1UJWclNBag를 브라우저에서 다시 재생해 약 6초와 14.3초의 버펄로 탑승 자세, 무리·먼지·협곡 구도를 관찰했다. 정확한 화남 조향 계수는 영상에서 측정하지 않았으며 사용자 설명에 따라 시험값을 구현했다. 분홍색 하트 게이지는 첨부 이미지의 표시 방향을 참고해 직접 UI 부품으로 작성했다.
- 화남은 서버가 0.55초 주기의 최대 2.4 studs 점프, 좌우 튕김과 평상시 35% 조향을 처리한다. 느낌표와 기존 화남 경고 후 종료를 유지한다. 정상 주행의 떨림 제거 구조를 유지하고 화남 동작을 일반 주행 진동으로 섞지 않는다. 수치는 조정 가능한 시험값이다.
- PC 마우스 떼기 점프/누르기 자동 줄을 제거했다. 서버 Jump 동작을 지상에서는 점프, 공중에서는 줄로 판정하고 탑승하는 동안의 키 입력은 예약하지 않는다. A/D와 기존 드래그 조향은 유지한다. 터치는 ContextActionService의 점프/줄 버튼으로 대응한다.
- TamingGauge는 타고 있는 몬스터의 표시 위치를 따르는 분홍색 원형 게이지/하트다. 갈아타기/종료 때 표시를 바꾸며 달리는 동안 하단 설명창을 숨긴다. 업로드한 외부 이미지 자산을 사용하지 않는다.
- 서버가 움직이는 무리의 상대 이동을 검사해 탑승 중 다른 몬스터 접촉을 판정한다. 협곡 안쪽 면을 실제 주행 경계와 맞추고 벽 접촉도 종료한다. 몬스터/벽 충돌은 즉시 적용하며 기존 2초 착지 보호는 바위에만 유지한다.
- CrashEffect는 실제 캐릭터를 파괴하지 않고 몸 부품의 로컬 사본을 흩뜨리고 회전/낙하/사라짐을 표시한다. 종료 중 원래 몸을 숨기며 재시작/캐릭터 교체 때 원래 가시성을 복원하고 임시 부품을 정리한다. 몬스터 모델을 파괴하지 않는다. 바위 충돌에도 같은 연출을 사용한다.

## 2026-10-08 — 탑승 떨림 수정과 사냥터 화면/동작 개선

- 사용자 피드백: 탑승 중 덜덜거림, 밋밋한 화면, 더 비스듬한 카메라, 구별되는 비행 자세와 역동적인 몬스터 달리기를 요청했다.
- 질문 답변으로 밝은 초원·층진 협곡·작은 먼지 효과·간결한 UI 방향을 확정하고 기획에 반영했다. 몬스터 종류와 포획/수익 규칙은 이번 미술 작업에서 새로 확정하지 않았다.
- 원인 구조: 서버가 매 프레임 모델 전체를 PivotTo로 옮기고 클라이언트가 같은 몸체 부품 CFrame을 달리기 자세로 덮어썼다. 서버는 판정용 MountRoot만 이동하고, 클라이언트는 고정 VisualTemplate 자세와 보간된 표시 위치로 몸체를 배치하도록 분리했다. 늦게 표시되더라도 이동한 원점을 잘못 기본 자세로 저장하지 않는다.
- 캐릭터와 카메라는 표시용 탑승 위치를 함께 따른다. 평상시 몸통의 빠른 상하 진동은 없애고 네 다리의 대각선 보폭/발 들어올리기를 확대했다. 무리의 발걸음 시작 위상도 분산했다. 화남 때의 의도적인 날뛰기는 유지한다.
- 공중에서는 상체를 앞으로 기울이고 팔다리를 벌린다. 탑승 자세로 돌아오며 종료/캐릭터 교체 때 관절과 기본 Animate 상태를 복원한다. 짧은 공중 궤적, 지면 그림자와 착지 후 발 뒤의 작은 먼지를 추가했다. 효과는 로컬에서 생성/정리하고 서버 판정에 참여하지 않는다.
- 카메라를 약 47도 사선으로 조정했다. 실제 Play 초기 구도 검사에서 발견한 추가 카메라 추적 지연을 제거했다. 화면 표현은 기본 카메라보다 뒤의 명시적인 렌더 순서에서 적용하고, 이미 보간된 표시 위치를 카메라가 바로 따라간다.
- 초원, 겹친 협곡 지층/풀 덮개, 가장자리 풀과 나무를 추가하고 UI를 축소했다. 배경 장식은 CanCollide/CanTouch/CanQuery가 모두 꺼져 있다. 바위 충돌 크기와 기존 생성 확률은 유지했다. 사냥 무리의 반복 이름표를 숨겼다.
- 검증: 최종 XML/참조/8개 내장 소스 일치와 단독 모델 검사, Luau 13개 파일 컴파일, 사냥 계산 20개와 가방 계산 15개, 변경 공백 검사 통과.
- 실제 Studio 부품/월드 검사 통과: 원점만 이동해 몸체 자세를 덮어쓰지 않음, 늦은 첫 표시의 기본 자세, 위치 보간, 네 다리와 등불, 공중 자세와 종료 시 관절/궤적 부품 정리. 기존 컨트롤러 검사 25개 통과.

## 2026-10-08 — 연속 탑승 흐름과 원작 구도/속도 보완

- 사용자 피드백: 첫 몬스터로 날아가 탑승 후 계속 타다가 일정 시간이 지나 느낌표와 화남이 나타나는 흐름을 요청했다. 계속 갈아타야 하는 것처럼 느껴지는 동작과 낮거나 다른 시점/속도 체감을 수정한다.
- 탑승 중 버튼을 뗐을 때 착지 직후 자동 재점프하는 코드를 제거했다. 빠른 클릭의 누르기/떼기 중 하나를 버리는 Hold 시간 제한도 제거했으며 공중 누르기는 즉시 줄 후보를 판정한다.
- 시작을 첫 몬스터로 날아가 탑승하는 연출로 연결했다. 길들이기 완료 안내를 계속 탈 수 있다는 내용으로 고쳤다. 화나면 머리 위 느낌표가 나타나며 경고를 이전 안내 문장이 가리지 않는다.
- 카메라는 길 중심을 따라가면서 옆에서 내려다보고, 좌우 이동은 화면에서 보이도록 수정했다. 주행 속도 40→64 studs/s, 무리 24→44, 공중 60→80으로 조정했다.
- 두 번째 영상의 약 8.825초/2464m와 15.192초/2720m에서 표시 속도 약 40.2m/s를 관찰했다. 표시 계수 0.625로 시험 주행 약 40m/s를 맞춘다. 계수는 실제 미터 변환이 아니며 영상 전체의 동일 속도를 보장하지 않는다.
- 카메라 오프셋과 화면 체감은 영상 기준의 시험 조정이며 원작과 완전히 동일하다고 주장하지 않는다.
- 이번 변경: 컨트롤러 회귀 검사 25개 통과. 빠른 누르기/떼기, 시작 비행, 착지 뒤 연속 탑승, 길들이기 뒤 주행 유지, 화남 속성과 종료를 포함한다. 배포 XML/참조/7개 소스 일치 검사와 Luau 파일 12개 컴파일, 변경 공백 검사 통과.
- 추가 실제 Play 검사는 새 검사용 Studio가 로그인 창에서 멈춰 실행 결과를 받지 못했다. 이번 변경의 Play 통과로 기록하지 않는다. 새 검사 세션과 이전에 남아 있던 제가 연 검사 세션만 식별해 종료했다. 사용자의 Studio 창은 종료하지 않았다. 느낌표 표시와 사선 카메라의 실제 화면 체감은 수동 확인이 남아 있다.

## 2026-10-08 — 카페/사냥터 기획 재정리와 루미돈 전환

### 사용자 확정

- 공간은 카페와 사냥터 두 곳이다. 카페에서는 보유 몬스터를 꺼내 동행/탑승하고 음성으로 소통한다. 사냥터에서는 Rodeo Stampede 방식으로 몬스터를 포획한다. 우선 사냥터를 제작한다.
- 보유 개체는 소환 없이도 각자 일정 간격과 금액으로 돈을 생산한다. 구매할 물품은 추후 사용자 결정이다.
- 같은 종류·같은 별 3마리로 다음 별 등급 1마리를 만든다. 최대 10성, 3/6/9성에서 모습과 생산량이 증가하는 진화를 한다.
- 외부 캐릭터 콘텐츠를 폐기하고 독자적인 디자인/이름으로 제작한다. 질문 답변으로 첫 몬스터는 등불을 단 블록 아기멧돼지 **루미돈**으로 확정했다.

- 현재 작업 파일과 기록을 정리하며 Git의 과거 커밋 자체는 다시 쓰지 않는다. 과거 검증 결과를 새 모델/새 코드의 결과로 가져오지 않는다.

- 실제 컨트롤러를 Studio 모델과 제어된 입력/시간으로 검사해 21개 통과. 착지 보호가 충돌을 막고 만료되는 것을 포함한다.
- 첫 실제 Play 검사에서 클라이언트의 RideAnimator가 아직 복제되지 않아 UI 생성 전에 실패했다. 필요한 모듈·월드 부품을 WaitForChild로 기다리도록 고쳤다.
- 수정 후 실제 Play 12개 검사 통과: UI 생성, 높은 카메라와 시야각, 시작/점프/줄/탑승, 착지 보호, 길들이기 지급/중복 방지, 종료 시 이동·시야각 복원, 재시작 보유 유지와 화남 종료. 테스트는 실제 서버/클라이언트 RemoteEvent를 사용하지만 마우스/터치 실물 조작이나 화면의 미술 체감 검사는 아니다.
- 검사에 사용한 별도 Studio 세션은 모두 종료됐다. 변경사항 공백 검사와 현재 파일의 폐기된 캐릭터 이름/참조 검색 통과.

### 미완료

- 실제 화면과 입력의 원작 대비 체감, 터치 기기, 다중 플레이어 검증.
- 카페 Place와 공간 이동, 영구 저장, 몬스터별 최종 수익표, 소환/동행/카페 탑승, 음성 채팅 설정, 합성/진화와 물품 구매.
- 현재 단일 사냥터 시험 파일을 두 공간이 연결된 완성판이라고 취급하지 않는다.
