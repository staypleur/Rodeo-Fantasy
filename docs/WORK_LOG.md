- 몸통에 한 걸음 주기의 위아래 움직임과 앞뒤 기울기를 추가하고 다리 진폭도 키웠다. 탑승자가 같은 표시 좌표를 따라 움직이며 카메라 높이와 서버 충돌 좌표는 유지한다.
- 가까운 무리의 발밑 먼지를 추가했다. 전체 먼지 개수와 수명을 제한하고 먼 몬스터는 기존 표시 거리로 제외한다.
- 기존 장애물 충돌 부품 안에 이끼 바위·돌조각 또는 쓰러진 통나무·밝은 단면·부러진 가지 장식을 넣었다. 배치 확률·충돌 크기는 유지한다. 외형 장식은 충돌과 줄 판정을 만들지 않는다.
- 공중 A/D·드래그는 클라이언트와 서버에서 무시한다. 공중 스페이스바 줄 던지기는 유지한다.
- 갈아타기 착지에만 서버가 0.6초/1.5배 전진 가속을 부여한다. 클라이언트 예측과 거리 표시는 같은 가속 시간을 사용하고 짧은 속도 궤적을 표시한다. 첫 탑승과 점프 후에는 갈아타기 가속을 유지하지 않는다.
- 탑승 이동이 캐릭터의 앞쪽 안장 오프셋을 매 틱 더하고 있었던 문제도 수정했다. 몬스터 기준 좌표에서 이동해 정해진 속도와 거리 계산이 일치한다.
- 영상은 브라우저에서 재생/장면 확인했다. 입력 제한은 사용자 설명, 가속 수치는 사용자 답을 근거로 한다. 영상만으로 원작의 정확한 가속 배율·시간을 측정했다고 주장하지 않는다.

- Luau 소스/검사 19개 컴파일, 무리 수치 2,984개, 사냥 계산 28개와 가방 계산 15개 통과. 겹친 바위 1개/2개에서 각 12개 이동 리듬으로 탈출·전진 재개를 검사했다.
- 배포 XML 구조/참조/12개 소스 일치와 단독 모델 검사 통과.
- 최종 실제 Studio 무리 관통 검사 3,600개와 추가 걸림 복구·몸통 높이 변화·무리 먼지 검사 통과. 일반 모델·거리 표지·이끼 바위와 통나무 장식·속도 궤적 검사 통과.
- 실제 컨트롤러 40개 검사 통과: 공중 좌우 입력 무시, 첫 탑승에 대시 없음, 갈아타기 1.5배 이동과 만료 후 정상 속도 복귀 포함.
- 최종 실제 서버/클라이언트 Play 40개 검사 통과: 기존 무리 회피·앉는 자세·줄·비행·포획·화남·충돌·복원과 공중 조향 제한·갈아타기 가속/궤적 포함. 이번 검사는 1인 Play이며 멀티플레이 완성 검사가 아니다.

- 코드·배포 파일·기획과 작업 기록은 로컬에 저장했다. 커밋/푸시는 실제 명령 결과로 구분해 사용자에게 안내한다.
