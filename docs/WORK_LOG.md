# 작업 기록

## 2026-10-08 — 사냥 전면 개편과 포켓몬 콘텐츠 전환

- 사용자 요청으로 이전 시험 캐릭터의 코드·모델·시안과 관련 현재 문서를 제거했다. 현재 파일 기준으로 정리하며 Git의 과거 커밋 자체는 다시 쓰지 않는다.
- 몬스터 콘텐츠는 포켓몬으로 변경한다. 첫 실험용 포켓몬은 파이리다.
- 사냥터와 포획을 로데오 스탬피드 기준으로 교체한다. 색깔 판정 막대, 최초 노란색 5초 버티기와 3초 동안만 가능한 갈아타기를 제거한다.
- 누르기/좌우 이동, 떼서 앞으로 점프, 공중에서 다시 눌러 줄 범위 내 다음 개체 잡기, 오래 타서 길들이기, 장애물 충돌과 사냥 종료/재시작을 연결한다.
- 파이리는 오래 타면 버펄로처럼 화나서 날뛰고 떨어뜨리는 행동을 요청했다. 공식 자료에서 확인되지 않은 정확한 시간/속도/범위는 시험용 조정값으로 구분한다.
- 달리는 파이리 무리, 협곡 길, 바위, 먼 구간/개체 정리를 추가한다. 길들이기 완료 후에도 계속 달리며 한 개체의 중복 지급을 막는다.
- 가방 수익·펫 동행 기획과 별 등급 성장 기획은 유지한다. 카페 공간과 직접 수령 조작, 동행 수, 진화 형태는 미정이다.
- 사냥 재시작/캐릭터 리셋은 이번 접속의 가방과 수익을 유지한다. 영구 저장/오프라인 수익/결제는 미구현이다.
- 변경 코드와 배포 파일을 검증한 뒤 아래에 실제 결과를 추가한다. 완성된 원작 전체 재현이라고 취급하지 않는다.
- 검증 결과: 순수 사냥 계산 20개, 가방 수익 15개, 게임 소스 7개/Studio 검사 3개 컴파일, 배포 XML/참조/소스 일치 검사 통과.
- 실제 Studio에서 파이리 구조/불꽃/두 다리 움직임, 달리는 무리, 줄 후보 제외, 바위 충돌, 높은 점프의 회피, 먼 개체 정리 검사를 통과했다.
- 실제 컨트롤러 소스를 Studio의 모델과 제어된 입력/시간으로 실행해 19개 검사 통과. 아날로그 조작과 NaN 입력 거절, 점프/줄/탑승, 미완료 진행 취소, 길들이기 한 번 지급, 재시작 가방 유지, 화남 경고/종료, 충돌/이동 복원을 확인했다.
- 첫 컨트롤러 검사에서는 검사 환경에 Raycast 전달이 빠져 실패했다. 실제 Studio Raycast에 연결한 뒤 재검사해 통과했다. 실행 코드의 해당 기능은 수정할 필요가 없었다.
- 자동 Play는 결과를 받지 못해 미완료로 기록한다. 제가 실행한 세션만 정리했으며 실제 마우스/터치/화면 체감은 수동 검증이 남아 있다.
- 현재 파일의 이전 캐릭터 이름/관련 참조가 남지 않았음을 검색했다. Git 과거 커밋은 보존한다.
