## 2026-10-06 — 앰버랫 탑승·포획 첫 프로토타입

### 확정된 답변
- 첫 몬스터는 앰버랫: 근접형, 불/포유류 시너지.
- 스킬은 전방의 적 1명에게 불꽃 이빨로 물기. 총기력 40, 일반 공격 4회 후 스킬 사용.
- 3m는 점프 거리다. 범위 내 몬스터를 클릭해 줄을 던지고 탑승한다.
- 탑승 중 자동 전진, A/D 좌우 이동을 적용한다.
- 왕복 막대에 스페이스바 1회 입력. 흰색이면 낙하 후 재도전, 노란색이면 추가 미니게임 없이 5초 후 포획, 주황색이면 즉시 포획한다.

### 구현
- 확정 내용을 기획서와 공용 설정에 반영했다.
- 서버의 거리/장애물/점유 검사, 점프와 줄 표시, 자동 이동, 포획 상태 전환을 구현했다.
- 한국어 안내, 카운트다운, 포획 막대, 거리 표시, 이번 접속 포획 수를 구현했다.
- 최초 85/14/1, 재포획 80/17/3 비율을 적용했다.
- `dist/RodeoFantasy-Capture.rbxlx`와 초보자용 `docs/STUDIO_SETUP.md`를 추가했다.
- 앰버랫의 최종 외형을 임의로 정하지 않고 이름표가 있는 회색 기능 테스트 블록을 사용했다.
- 이동/막대 속도와 점프 연출 시간은 `Config.Prototype`의 테스트 조정값으로 분리했다.

### 검증
- Luau 판정 테스트 26개, 소스 4개 컴파일, 공용 로직 정적 분석, 배포 파일 구조 및 소스 일치 검사 통과.
- 경계값 검사에서 재포획 주황색 시작점의 부동소수점 오차를 찾아 수정했다.
- 실제 설치된 Roblox Studio에서 배포 파일 로드, 공용 모듈 실행, 계층 구조, 모델 위치 이동 검증 통과.
- 실제 Studio Play 모드의 서버/클라이언트 자동 검사 13개 통과. 거리 거절, 탑승, 이동, 세 가지 포획 판정, 중복 입력 방지, 재포획 비율을 확인했다.
- 검사 결과와 남은 수동 확인 항목은 `docs/VALIDATION.md`에 기록했다.

### 남은 범위
- 외형, 정식 지역, 전투 실행, 영구 데이터 저장은 아직 구현하지 않았다.
- 사용자 플레이로 이동 속도, 막대 속도와 조작감을 확인하고 조정한다.
- 온라인 지연 보정과 모바일 조작은 별도 개발이 필요하다.

## 2026-10-06 — 이동 속도 조정 및 연속 미니게임 요청

- 사용자 피드백: 현재 속도가 너무 느리며, 한 번에 잡히지 않으면 미니게임이 계속되어야 한다.
- 테스트 전진 속도를 18 → 40 studs/s(약 2.2배), 좌우 이동을 12 → 22 studs/s로 조정했다.
- 연속 미니게임과 기존 노란색 5초 포획의 관계는 확인 중이다. 타이머 유지/재시작/자동 포획 제거 중 원하는 방식을 질문했다.
- 답변 전에는 포획 규칙을 임의로 바꾸지 않는다. 이번 파일에는 이동 속도 조정만 반영한다.
