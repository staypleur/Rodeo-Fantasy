# 현재 Studio에 수정 적용

최신 UI·유리 천장·제공 부화실 모델 적용은 `docs/APPLY_LOBBY_MODULES.md`를 따릅니다. 아래 불투명 천장 확인 항목은 이전 결정입니다.

색상이 들어온 모델을 유지하기 위해 현재 열어 둔 장소에 적용합니다.

1. Roblox Studio에서 **중지(빨간 네모)**를 눌러 Play를 끝내고 **Ctrl+S**로 저장합니다.
2. 프로젝트의 `dist/FixCurrentLobbyHunt.commandbar.lua` 파일을 메모장으로 열어 **Ctrl+A → Ctrl+C**로 전체를 복사합니다.
3. Studio의 **보기 또는 창 → 명령 모음(Command Bar)**을 엽니다. 아래 명령 모음에 붙여 넣고 Enter를 누릅니다.
4. 출력에 **LOBBY_HUNT_FIXES_INSTALLED**가 보이면 **Ctrl+S**로 저장합니다. 다른 코드가 있어 중단됐다는 오류가 뜨면 변경하지 않고 중단하므로 그 문장을 전달해 주세요.
5. **Play**로 아래를 확인합니다.

- 로켓 양옆의 거리·도감 랭킹과 오른쪽 아래 상점·룰렛 버튼. 버튼은 마우스/터치로 열고 ×로 닫습니다. 상품과 보상 기능은 아직 없습니다.
- 로비 표면에 Stud가 없는지, 천장 위로 하늘이 보이지 않는지, 8개 입구가 로켓을 향하는지.
- 내 부화실에는 이름만 표시되고 주인이 없는 간판은 비어 있는지.
- 로켓 앞·뒤·좌·우에서 가까이 가면 E를 꾹 누르는 안내가 보이는지.
- 사냥 중 모스랫이 앞으로 달리고 다리가 움직이는지, 시작 몬스터가 새로 길들여져 가방에 추가되지 않는지.
- 사망 후 **로비로 돌아가기**가 동작하는지.

입력 모델과 색상은 유지합니다. 알려진 Workspace 미리보기/가져오기 모델은 ServerStorage의 `LobbyHuntFixBackup_…`으로 이동합니다. 중앙 로켓과 게임용 모스랫은 유지합니다. 이름이 다른 잔여 모델은 자동으로 삭제하지 않습니다.

랭킹의 실제 저장·조회는 게시한 게임에서 확인해야 합니다. 로컬 Studio에서는 게시 안내가 표시될 수 있습니다. 코드와 모의 동작 검사는 통과했으며 실제 Studio·PC·모바일 화면 및 성능 검증은 아직 하지 않았습니다.
