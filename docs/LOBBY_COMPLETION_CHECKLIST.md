## 사용자 시험 순서

1. Studio 시험 중이면 Shift+F5로 중지한다. 현재 편집 파일을 보관하려면 Ctrl+S로 저장한다.
2. Ctrl+O에서 프로젝트 dist 폴더의 RodeoFantasy-LobbyFinishedLayout.rbxlx를 연다.
3. F5로 시작한다. 상점 지붕이 높아졌는지, 랭킹에 지붕 없이 큰 게시판이 있는지, 두 목장 사이 바깥쪽에 아치/정원이 있는지 본다.
4. 목장 입구/광장을 걷고 몬스터를 배치해 바닥과 부품이 깜빡이는지 본다. 바구니까지 올라가 기존 출발 조작을 확인한다.
5. 이 파일에 새 고래 디자인은 적용하지 않았다. 이 시험은 DataStore 실제 저장 또는 실제 모바일 성능 검증을 대신하지 않는다.
