- 이번 실제 Play 자동 검사는 Studio CLI에서 완료 결과를 반환하지 않았다. 현재 UI/사다리 오르기/8인 네트워크 화면·소리 체감을 통과했다고 주장하지 않는다. F5 수동 확인 절차는 STUDIO_SETUP에 있다.
- 게시 경험의 실제 랭킹 저장/재접속/서버 간 갱신, 다른 언어 공개 자동 번역, 실제8클라이언트/모바일 성능.
- 승인된 A계열 모델은 기본 Roblox 부품으로 구현한 첫 외형이다. 원본 시안과 동일한 커스텀 메시가 아니며 게임 안에서의 미술 체감은 사용자 확인이 필요하다. 3·6·9성 생산량과 합성 조작은 미정이고 현재 야생은1성만 등장한다.
- 가방/잔액 영구 저장, 알/배합/유료 목장 확장/카페/합성·진화/상점 판매는 후속 범위.
