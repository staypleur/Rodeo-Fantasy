- native Studio 서버 컨트롤러46개: 주행·갈아타기·대시·충돌·포획·잡초까마귀 속도/같은 길들이기/종별 수익.
- native Studio 종별 모델/늦은 몸통 복구/잎 날개 동작, 목장 소유/거리·최대2마리·회수·목장 무먼지, 지상/비행 충돌 분리·높은 벽·비행 상자 통과.

## 미확인

- 이번 실제 Play 자동 검사는 Studio CLI에서 완료 결과를 반환하지 않았다. 현재 UI/사다리 오르기/8인 네트워크 화면·소리 체감을 통과했다고 주장하지 않는다. F5 수동 확인 절차는 STUDIO_SETUP에 있다.
- 게시 경험의 실제 랭킹 저장/재접속/서버 간 갱신, 다른 언어 공개 자동 번역, 실제8클라이언트/모바일 성능.
- 신규 초원5종의 승인 외형·진화형 모델, 새 등장 구간·길들이기/생산·크기별 밀치기/5초 장애물 복구는 디자인 선택 뒤 통합한다. 현 파일은 교체 전 루미돈/잡초까마귀 시험이다.
- 가방/잔액 영구 저장, 알/배합/유료 목장 확장/카페/합성·진화/상점 판매는 후속 범위.

실행: `python tools/build_place.py`, `python tests/check_place.py`, pure `luau tests/*.luau`; native 검사들은 Studio CLI 사본에 실행한다. 미술 구조 PNG는 Studio 화면 캡처가 아니다.
