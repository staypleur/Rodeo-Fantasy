# 파이리 연속 사냥 검증

## 자동 검사

변경된 장소의 모델·연속 사냥 계산·가방 계산·배포 파일을 검사한다. 실제 결과는 작업 기록에 남긴다. 컴파일이나 구조 검사만으로 실제 플레이 전체가 통과했다고 취급하지 않는다.

- 순수 연속 사냥 계산 20개, 가방 수익 계산 15개 검사 통과.
- 게임 소스 7개와 Studio 검사 파일 3개 컴파일, XML 참조와 원본 소스 일치 검사 통과.
- Studio 실제 모델/월드 검사 통과: 파이리 형태/불꽃, 두 다리 움직임과 원점 유지, 야생 무리 이동, 점유 개체 보존, 이전 탑승 대상 제외, 바위 충돌/높은 점프 회피, 먼 개체 정리.
- Studio의 실제 모델과 제어된 입력/시간으로 원본 사냥 컨트롤러를 실행해 19개 검사 통과. 시작/점프/줄/길들이기/중복 지급 방지/재시작 보유 유지/화남 종료/충돌/이동 복원을 확인했다. 실제 플레이어 네트워크나 마우스 입력 검사는 아니다.
- 자동 Play 세션은 결과를 반환하지 않아 통과로 기록하지 않았다. 검사용 세션은 종료했다. 화면과 입력 체감은 아래 항목으로 확인한다.

## 수동 플레이 확인

- [ ] F5 후 사냥 시작을 누르면 파이리를 타고 자동으로 전진한다.
- [ ] 파이리 무리가 계속 달리고 앞길에 바위가 보인다.
- [ ] 누른 채 좌우 움직임과 A/D가 정상 작동한다.
- [ ] 손을 떼면 점프하고 공중에 노란 줄 범위가 보인다.
- [ ] 다시 누르면 범위 안의 다음 파이리로 줄이 연결되고 탑승한다.
- [ ] 충분히 오래 타면 길들이기가 한 번만 지급되고 계속 달릴 수 있다.
- [ ] 길들이기 전에 점프하면 진행이 취소되며 다음 개체에서 처음부터 시작한다.
- [ ] 화남 경고 뒤 점프하면 이어 달릴 수 있고, 버티면 떨어져 종료된다.
- [ ] 바위 충돌/공중에서 잡기 실패는 사냥 종료로 이어진다.
- [ ] 다시 사냥하기/캐릭터 리셋은 접속 중 가방과 수익을 유지한다.
- [ ] 다른 플레이어가 탄 파이리는 잡을 수 없다.
- [ ] Stop 후 Play는 가방과 돈을 초기화한다.
- [ ] 터치 실제 기기에서 누르기/떼기/좌우 조작과 화면 크기를 확인한다.

## 한계

원작의 모든 지형·포켓몬·능력·정확한 수치를 재현한 완성판이 아니다. 첫 파이리 모델과 핵심 루프의 실험이다. 직접 수령 조작, 펫 동행, 진화, 영구 저장과 결제는 미구현이다.

```text
python tools/build_place.py
python tests/check_place.py
luau tests/hunt_rules.luau
luau tests/bag_rules.luau
```

Windows Luau 도구가 한글 경로를 읽지 못하면 소스/테스트와 실행기를 같은 영문 임시 경로에 복사해서 검사한다.
