# 루미돈 사냥터 검증

이번 변경의 결과만 작업 기록에 남긴다. 소스 컴파일과 구조 검사만으로 실제 Play와 화면 체감까지 통과했다고 취급하지 않는다.

## 자동 검사

- `python tools/build_place.py`: 사냥 장소와 루미돈 모델 생성
- `python tests/check_place.py`: XML 구조/참조/내장 소스와 단독 모델 검사
- `luau tests/hunt_rules.luau`: 순수 사냥 계산 24개
- `luau tests/bag_rules.luau`: 가방 수익 계산 15개
- `tests/studio_smoke.luau`: 실제 Studio 루미돈 구조/등불/네 다리 동작과 무리/줄/장애물/정리 검사
- `tests/studio_controller_smoke.luau`: 실제 컨트롤러를 Studio 모델과 제어된 입력/시간으로 검사. 착지 보호/만료, 포획 한 번 지급, 갈아타기와 종료/재시작 포함. 실제 네트워크/마우스 검사는 아니다.
- `tests/studio_hunt_playtest.luau`: 실제 Play 자동 검사. 결과를 확인한 경우에만 통과로 기록한다.

Studio 자동 검사는 [공식 CLI](https://create.roblox.com/docs/studio/command-line-interface)의 `--task RunScript --localPlaceFile ... --runScriptFile ... --outputFile ... --quitAfterExecution`로 별도 사본에서 실행한다.

## 수동 확인

- [ ] 사냥 시작 후 등불을 단 루미돈을 타고 자동 전진한다.
- [ ] 시작할 때 첫 몬스터로 날아가 탑승한다. 탑승 중 스페이스바를 눌러도 착지 후 자동 재점프하지 않는다.
- [ ] 앞길과 무리를 내려다보고, 점프해도 카메라가 들썩이지 않는다.
- [ ] 스페이스바/공중에서 스페이스바로 점프와 줄 전환을 이어간다. A/D와 마우스 좌우 조작도 작동한다.
- [ ] 직전에 탄 개체와 다른 플레이어가 탄 개체는 잡기 후보에서 제외된다.
- [ ] 바위 착지 보호가 끝난 뒤 바위 충돌은 종료된다. 몬스터/벽 충돌은 즉시 종료된다.
- [ ] 같은 개체를 오래 타면 한 번만 가방에 추가된다. 완료 후에도 달린다.
- [ ] 길들이기 전에 갈아타면 이전 진행이 취소된다.
- [ ] 느낌표 경고 뒤 계속 날뛰지만 시간만으로 떨어지지 않는다. 화난 동안에도 스페이스바로 점프/갈아타기가 가능하다.
- [ ] 길들이기 성공 후 같은 개체를 계속 탈 수 있고, 화날 때 느낌표와 반복 점프/좌우 튕김/조향 감소가 나타난다.
- [ ] 사선으로 내려다보는 카메라는 길 중심을 따라가며, 좌우 조작 시 주행자의 화면 위치가 변한다. 영상과 속도·앞길 구도를 비교한다.
- [ ] 다음 개체 잡기 실패와 장애물 충돌 후 재시작할 수 있다.
- [ ] 사냥 재시작은 접속 중 보유/수익을 유지한다. Stop 후 Play는 초기화한다.
- [ ] 루미돈의 네 다리·발·등불이 함께 움직이며 높은 시점에서도 알아볼 수 있다.
- [ ] 탑승 몸통의 빠른 떨림이 없고 캐릭터와 몸체가 같은 표시 위치를 따른다.
- [ ] 공중에서 몸을 기울이고 팔다리를 좌우로 뻗으며, 착지하면 탑승 자세로 돌아온다. 종료 뒤 원래 캐릭터 애니메이션이 돌아온다.
- [ ] 밝은 초원/협곡 장식이 줄이나 충돌 판정을 막지 않으며 먼지와 공중 궤적이 사라진다.
- [ ] 실제 터치 기기와 다중 플레이어로 확인한다.

- [ ] 몬스터의 화면 왼쪽 아래 원형 하트 게이지가 차고 갈아타면 새 개체 진행을 표시한다. 길들이기가 끝나면 게이지가 숨겨지고, 이후 화남은 그대로 발생한다. 달리는 동안 하단 설명창은 숨겨진다.
- [ ] 몬스터/벽 충돌 때 플레이어만 흩어지고 재시작하면 정상 모습으로 돌아온다.

## 앉는 자세·줄·거리 표지 추가 확인

- 실제 Play에서 오른쪽 허벅지가 캐릭터 앞 방향으로 굽혀져 앉는지 확인한다. 기본 Motor6D와 새 AnimationConstraint 모두 처리하며 새 관절의 자세 적용은 PreSimulation에서 한다.
- 탑승 중 머리 위 줄이 계속 회전하고, 스페이스바 점프 때 회전 줄은 사라지는지 확인한다.
- 착지 먼지와 지면 속도 자국, 귀·꼬리와 조향 기울기를 확인한다.
- 1,000m마다 바닥선·거리 표지판을 지나고 재시작하면 거리와 표지가 초기화되는지 확인한다.
- 이 검사들은 완성된 미술 품질이나 다양한 체형·모바일 체감을 보장하지 않는다.

## 무리 이동·밀도 조정 확인

- 일반 무리가 앞쪽 바위를 좌우로 피해서 지나고 협곡 경계를 벗어나지 않는지 확인한다.
- 개체별 좌우 움직임과 실제 진행 방향에 따른 몸의 회전·기울기를 확인한다.
- 서버 좌표뿐 아니라 클라이언트의 보간된 몸도 바위를 통과하지 않는지 확인한다.
- 플레이어 탑승 개체에는 자동 회피가 적용되지 않으며 기존 직접 조향·충돌 판정을 유지한다.
- 몬스터 50% 감소/기존 바위 50% 증가는 배치 빈도 시험값이다.

## 걸림 복구·들썩임·가속 확인

장애물과 처음부터 겹친 몬스터와 겹친 바위 두 개 사이의 몬스터가 옆으로 탈출한 뒤 전진하는지 확인한다. 달리는 몸통의 높이 변화, 무리 먼지, 이끼 바위와 통나무 장식 생성도 검사한다. 공중 좌우 입력을 서버와 클라이언트 모두 무시하고, 갈아탄 뒤 0.6초/1.5배 가속과 속도 궤적이 나타난 뒤 정상 속도로 복귀하는지 확인한다. 탑승 정렬 검사는 고정된 월드 오프셋 대신 실제 들썩임 방향을 기준으로 한다.
