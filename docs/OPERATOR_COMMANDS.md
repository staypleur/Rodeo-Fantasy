# 운영자 명령어 사용법

운영자는 사용자에게 확인받은 Roblox 계정 **puller3313**만 허용한다. 서버가 Roblox UserId를 조회해 비교한다. 명령어를 입력할 때마다 별도 비밀번호 창에서 확인해야 실행된다. 다른 계정은 비밀번호를 알아도 실행할 수 없다.

## 처음 비밀번호 설정

1. 파일 탐색기에서 프로젝트의 `tools` 폴더를 연다.
2. `운영자비밀번호설정.cmd`를 더블클릭한다.
3. 창에서 새 비밀번호를 입력하고 Enter를 누른다. 12자 이상이며 입력 글자는 표시되지 않는다. Roblox 로그인 비밀번호와 다른 운영자 전용 비밀번호를 사용한다.
4. 같은 비밀번호를 다시 입력한다.
5. ‘개인용 게임 파일 저장 완료’가 나오는지 확인한다. 생성 경로는 프로젝트의 `dist/LocalOperator/RodeoFantasy-OperatorConfigured.rbxlx`다.
6. Studio 실행 중이면 중지한 뒤 Ctrl+O로 이 개인용 파일을 열고 F5로 실행한다. 공개 게임에서도 사용하려면 이 파일을 기존 경험에 게시한다. 이번 작업에서 공개 게임 게시를 대신 실행하지 않았다.

입력 비밀번호 원문은 파일에 저장하지 않고 서버 전용 모듈에 무작위 salt와 SHA-256 검증값을 넣는다. 개인용 파일 폴더는 Git에서 제외한다. 비밀번호를 채팅·작업 기록·GitHub에 보내지 않는다. 검증값도 인증 정보이므로 개인용 파일을 공개 저장소에 올리지 않는다.

## 몬스터 지급

로비에서 채팅 입력창을 열고 다음을 입력한다.

```
/monster 모스랫 3
/monster 모스랫 6
/monster 모스랫 9 3
```

마지막 숫자는 마릿수다. 생략하면 1마리, 최대10마리. 별은1~9까지 정수로 입력한다. 모스랫·브램블보어·바인팽·쏜크로·엘레바인을 지원한다. 저장 ID인 MeadowMouse·GrassBoar·TreeWolf·Weedcrow·RockElephant도 사용할 수 있다.

운영자 확인 창이 뜨면 설정한 비밀번호를 넣고 확인을 누른다. 가방을 R로 열어 별과 마릿수가 늘었는지 확인한다. 비밀번호가 틀리면 지급하지 않는다. 5회 실패하면60초 동안 잠기며 확인 요청은45초 뒤 만료된다. 창을 닫으면 해당 요청을 취소한다. 매 명령어마다 다시 확인하며 로그인 승인을 재사용하지 않는다.

지급 개체는 기존 가방 개체와 같은 성별50/50·생산·목장 배치 규칙을 사용한다. 실제 포획이 아니므로 도감 발견/포획 수·랭킹에 추가하지 않는다. 가방은 기존처럼 접속 중 저장이며 재접속 영구 보관은 별도 미완료다. 사냥 중 지급은 거절하고 로비에서 사용한다.

아직 새 모스랫3·6·9성 디자인은 검토안이며 게임 적용 전 승인 대기다. 현재 명령어는 기존 성장 단계 모습으로 지급한다.

## 업데이트와 검증 범위

새 게임 파일을 전달받은 뒤 설정 도구를 다시 실행하면 최신 공개 수정본을 기반으로 개인용 파일을 만든다. 이 도구는 개인용 파일의 수동 편집 내용을 합치지 않는다. 개인용 파일을 직접 수정했다면 먼저 별도로 보관한다.

서버 인증·잘못된 요청·재사용·만료·취소·반복 실패·실제 가방 지급과 비밀번호 입력창의 가림/지우기는 CLI/API 모형 검사로 확인했다. 실제 Studio 채팅, 공개 게임의 계정 조회, PC/모바일 키보드·화면·성능은 별도로 확인해야 한다.

API 확인: [TextChatCommand](https://create.roblox.com/docs/reference/engine/classes/TextChatCommand), [Player](https://create.roblox.com/docs/reference/engine/classes/Player), [ChatVersion](https://create.roblox.com/docs/reference/engine/enums/ChatVersion).
