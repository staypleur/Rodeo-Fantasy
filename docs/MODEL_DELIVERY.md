# 새 몬스터 모델 제작 기준

사용자 확정: 사냥터용 약3,000삼각형 / 로비·카페용 약10,000삼각형. 이는 게임의 초기 제작 목표이며 Roblox의 고정 제한이나 휴대폰 성능 보장이 아니다.

- 같은 몬스터의 두 버전으로 제공한다. 사냥터용은 후면 실루엣·다리·탑승할 등 형태, 소셜용은 얼굴과 가까이 보는 형태를 우선한다. 삼각형 수는 정사각 면/정점 수와 구분해 내보낸 파일에서 검사한다.
- 원본과 GLB 또는 FBX를 보관한다. 메시·텍스처·뼈·애니메이션 파일을 함께 제공한다. 두 버전의 크기·정면·원점·뼈 이름/구조를 같게 맞추면 연결이 수월하다. 단순 감면 후 다리 관절이 찌그러지지 않는지 확인한다.
- 색 텍스처1024×1024, 사냥용512 버전은 초기 권장안. 먼저 원본 색·UV·재질도 보존하고 실제 게임에서 화질을 비교한다. 재질/메시 분리와 반투명 효과를 불필요하게 늘리지 않는다.
- 가방 소유는 데이터로 보관한다. 수집한 모든 모델을 동시에 화면에 표시하지 않는다. 로비는최대8마리/카페최대20마리, 알부화소총32칸. 먼 거리 모델은 간략화 검토 대상이다.
- 초보자 전달 방법: `assets/models/incoming` 폴더에 파일을 넣거나 파일 위치를 채팅에 알려준다. 이름/정면/크기/다리 애니메이션·탑승 등 위치는 파일을 받은 뒤 확인한다. 첫 몬스터는 무료모스랫1성이고 새모델제공후연결한다.

실제 저사양 휴대폰에서20마리·아바타·카페맵을 함께 실행해 FPS/메모리/프레임 끊김을 확인해야 한다. Studio 화면비 에뮬레이터가 휴대폰 메모리를 대신 측정하지 않는다. 근거: [Roblox 성능 설계](https://create.roblox.com/docs/performance-optimization/design), [성능 개선](https://create.roblox.com/docs/performance-optimization/improve).
