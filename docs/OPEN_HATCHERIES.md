# 열린 부화소와 로비 정리

2026-10-11: 현재 Studio에서 적용·저장했다. 장소 전체를 재빌드하지 않는다.

- 개인실 8개에 사방이 열린 낮은 알 받침 4개씩, 총 32개.
- 인큐베이터·문틀·문짝·콘솔·새끼 캡슐은 로비에서 제거하고 ServerStorage에 복구용 원본을 보관.
- 알 버튼 → 부화소 1~4 → 알 선택. 자리당 알 1개. 알이 없는 경우 기존 준비 중 안내를 유지한다. 부화 시간·결과는 아직 미정이다.
- 전체/개인실 천장, 나무, 장식 간판, 물리 상점·룰렛·배틀패스 게시판 제거. 상점·룰렛 화면 버튼은 유지.
- 실제 랭킹은 로켓 좌우, 바닥에서 세운 판이며 충돌하지 않는다.
- 불투명 바닥 받침으로 틈을 메우고 개인실 벽의 모서리는 면이 겹치지 않게 연결. 행성은 최대 폭 360stud로 확대.

다른 기존 장소에 다시 적용해야 할 때만:

1. Roblox Studio에서 `dist/RodeoFantasy-New.rbxlx`를 열고 Play를 중지한다.
2. `dist/InstallOpenHatcheries.commandbar.lua` 파일을 열어 전체 코드만 복사한다. Markdown의 백틱이나 실행 로그는 복사하지 않는다.
3. Studio **보기 → 명령 모음(Command Bar)**에 붙여넣고 실행한다. 출력의 `OPEN_HATCHERIES_INSTALLED`를 확인한다.
4. 같은 방법으로 `dist/CleanupLobby.commandbar.lua`를 실행한다. `LOBBY_CLEANUP_INSTALLED`를 확인한다.
5. Ctrl+S로 저장한 후 Play를 눌러 알 버튼의 4개 자리, 열린 출입구, 로켓 옆 랭킹을 확인한다.

스크립트는 기존 코드를 사전 검사하고 변경 대상만 백업한다. `별도 변경된 코드`/`코드가 달라 중단`이 나오면 기존 코드를 강제로 덮어쓰지 않는다. 옛 전체 로비 설치기를 다시 실행하면 이전 천장·캡슐 배치가 돌아올 수 있다.

회색 인큐베이터의 텍스처 원인은 확정하지 못했으며 사용자 요청대로 해당 모델을 사용하지 않는 배치로 변경했다. 최종 편집 화면에서 확대 행성의 보라/청록 색상과 고리 표시를 확인했다. 이전 HTTP502 재발 여부·실제 모바일 성능·실제 알을 가진 계정의 재접속 표시 검증은 별도다.
