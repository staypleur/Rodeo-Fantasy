# 로데오 스탬피드 영상 참고

2026-10-08 사용자가 게임 제작 참고용으로 제공했다. 브라우저에서 재생 화면을 확인한 관찰이며, 영상의 모든 규칙을 이 게임의 확정 규칙으로 취급하지 않는다.

후속 사용자 요청: 영상의 사냥 플레이와 같게 만들고 Roblox에서 구동한다. 단순 카메라 참고를 넘어 달리는 몬스터 무리와 점프/줄/갈아타기 흐름을 맞추는 것이 목표다. 현재 프로토타입은 정지한 테스트 몬스터와 평지여서 목표와 차이가 있다. 기존 색깔 막대 포획을 유지할지 영상 기준으로 변경할지는 질문 중이다.

- [괴물 니엔 포획](https://www.youtube.com/shorts/X9VWDOpwObY): 높은 시점에서 앞쪽 길과 여러 동물이 보인다. 캐릭터가 동물을 타거나 공중으로 이동하는 장면, 줄의 고리, 이동 거리 표시를 확인했다.
- [디아 버펄로와 트로잔 얼룩말 길들이기](https://www.youtube.com/shorts/J1UJWclNBag): 높은 시점에서 좁은 길과 앞서 달리는 동물들이 보인다. 서로 다른 동물을 타는 장면과 이동 거리 표시를 확인했다.

이번 적용: 탑승 카메라의 높이/앞길 시야, 앰버랫의 기본 다리 움직임과 몸 기울기, 테스트 바닥 표식으로 이동감 개선. 원작의 동물·모델·텍스처·소리를 복사하지 않고 프로젝트의 앰버랫 모델을 사용한다.

사용자 확정 후 갈아타기도 연결했다. 미니게임 시작 전 3초 동안 3m 안의 다른 몬스터를 클릭하며 이전 포획을 취소하고 새 탑승 후 3초부터 시작한다. 장애물, 숨겨진 동물 해금 조건, 원작의 길들이기 방식은 확정하지 않았다. 기존 3초 후 미니게임, 노란색 최초 5초 버티기 규칙을 유지한다.
