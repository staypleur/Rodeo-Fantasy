# Rodeo Fantasy

귀여운 아기부터 웅장한 진화형까지 독자 판타지 몬스터를 포획해 카페에서 펫으로 데리고 다니고, 가방에 보유한 몬스터가 돈을 생산하는 Roblox 게임입니다. 게임은 로비·카페·사냥터로 구성합니다. 현재 파스텔 로비와 초원 사냥터를 같은 시험 장소 안에서 연결했고, 카페는 로비 다음에 만듭니다.

사냥은 Rodeo Stampede의 자동 전진 → 좌우 이동 → 점프 → 줄로 갈아타기 → 오래 타서 길들이기 흐름을 참고합니다. 외부 게임의 자산과 캐릭터는 사용하지 않습니다.

PC는 **A/D 좌우 이동, 스페이스바 점프, 공중에서 다시 스페이스바로 줄 던지기**를 사용합니다. 몬스터 왼쪽 아래 원형 하트 게이지가 차고 길들이기가 끝나면 숨겨집니다. 이후 화나면 계속 뛰고 조종이 어려워지지만 자동으로 떨어지지는 않습니다. 화난 동안에도 스페이스바로 점프할 수 있습니다. 다른 몬스터나 벽과 충돌하면 플레이어 부품이 흩어지는 연출 뒤 재도전합니다.

초원 신규 5종의 1·3·6·9성 디자인을 선택하는 단계입니다. 기존 시험 파일에는 교체 전 루미돈과 잡초까마귀가 들어 있으며, 신규 종은 외형 선택 후 적용합니다.

## 실행 파일

- `dist/RodeoFantasy-Capture.rbxlx`: 파스텔 로비·비행장 이동·초원 사냥 코드와 루미돈이 포함된 시험 장소
- `dist/Lumidon.rbxmx`: 다른 장소에 삽입할 수 있는 루미돈 외형 모델
- `assets/models/lumidon-brick-preview.png`: 실제 모델 부품에서 만든 구조 미리보기. Studio 스크린샷은 아닙니다.
- `tools/build_place.py`: 장소와 모델 생성
- `tools/lumidon_model.py`: 루미돈 부품 설계
- `tools/lobby_map.py`: 로비의 편집 가능한 Roblox 부품 설계
- `assets/maps/lobby-layout-preview.png`: 실제 로비 부품의 위쪽 배치도 (Studio 화면 아님)
- `tools/preview_lobby.py`: 로비 배치도 생성
- `tools/preview_lumidon.py`: 구조 미리보기 생성

## 현재 상태

첫 입장은 로비입니다. 사방이 벽으로 둘러싸이고 하늘이 열린 중앙 광장·작은 천막 상점·블록 비행선, 개인 구역 8개와 각 구역의 목장 8개(총 64개)가 있습니다. 중앙 비행선에 가까이 가면 사냥터로 가고 종료 후 로비로 돌아올 수 있습니다. R 키/화면 버튼으로 로비 가방을 열어 몬스터 모습·별·생산량을 봅니다. 영어 기본, 한국어/일본어 로컬 번역 및 다른 언어 Roblox 번역 연결을 제공하며 공개 자동 번역 설정은 게시 후 필요합니다. 가방 수와 모인 돈은 로비에서만, 사냥터의 정보 HUD는 미터만 표시합니다.

초원에서 탑승·연속 주행·점프·줄·갈아타기·길들이기·지속되는 화남·장애물 충돌·재시작·접속 중 가방 수익을 시험할 수 있습니다. 착지 보호는 없습니다. 주행 중 공유 무리는 길 양쪽 동굴에서 보충합니다. 8명의 위치를 함께 확인하고 가까운 무리를 공유합니다. 1,000m에서 멈춥니다.

공개 서버 최대 8명은 Creator Dashboard에서도 설정해야 합니다. 카페, 펫 동행, 목장에 실제 몬스터 넣기·배합·알, 상점 판매, 영구 저장, 합성·진화, 음성 채팅 설정과 실제 여러 Place 이동은 아직 구현하지 않았습니다. 여러 플레이어와 모바일 실기기 검증도 후속 작업입니다.
