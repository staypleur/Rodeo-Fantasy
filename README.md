# Rodeo Fantasy

Roblox에서 만드는 몬스터 포획과 펫 동행 게임입니다.

몬스터를 타고 이동하며 포획하고, 자신의 가방 속 몬스터가 생성하는 돈을 법니다. 고양이카페 형식으로 방향을 바꾸었으며 보유 몬스터를 펫처럼 데리고 다니고 다른 플레이어에게 보여주는 기능을 계획합니다. 소환이나 전시는 수익 발생의 조건이 아닙니다. 3성·6성·9성에서 진화하며 수익도 증가합니다. 전투와 모든 시너지 시스템은 제거했습니다.

돈은 기본적으로 직접 수령하며, 자동 수령은 한 번 구매하면 영구 이용하는 유료 기능으로 제공할 계획입니다. 가격과 적용 범위는 아직 정하지 않았습니다.

## 현재 상태

동물원과 우리 배치 시스템을 폐기했습니다. 포획한 앰버랫은 가방에 들어가며 한 마리당 2초에 1원을 쌓습니다. 화면에 가방 마릿수와 모인 돈을 표시합니다. 새로운 직접 수령 조작, 동행 마릿수, 카페 공간은 사용자 답변 후 구현합니다.

앰버랫 탑승·포획 기능의 첫 프로토타입입니다. [Studio 테스트 파일](dist/RodeoFantasy-Capture.rbxlx)을 열어 사용할 수 있습니다.

범위 내 클릭 → 줄 던지기와 3m 이내 점프 → 자동 전진과 A/D 이동 → 탑승 3초 후 포획 미니게임을 구현했습니다. 성공하면 이번 접속의 포획 수가 증가합니다.

노란색 판정 후에도 미니게임은 5초 동안 계속됩니다. 다시 노란색을 맞혀도 남은 시간이 초기화되지 않으며, 흰색은 낙하, 주황색은 즉시 포획입니다.

사용자가 제공한 영상의 높은 시점과 달리기 느낌을 참고해 카메라, 다리 움직임/좌우 기울기, 임시 바닥 표식을 개선했습니다. [영상 참고 기록](docs/VIDEO_REFERENCES.md)에 관찰과 적용 범위를 구분했습니다. 미니게임 전 3초 동안 3m 안의 다른 앰버랫을 클릭해 갈아탈 수 있습니다. 이전 포획은 취소되고 새 탑승 후 3초부터 다시 시작합니다.

사용자가 선택한 B 시안의 기본형 앰버랫을 Roblox 기본 부품으로 제작해 테스트 장소에 적용했습니다. 큰 귀, 긴 꼬리, 주황빛 갈색 몸과 작은 불꽃이 특징입니다. 펫 소환·동행, 직접 수령 조작, 유료 자동 수령, 진화, 영구 저장은 아직 구현하지 않았습니다. 가방과 수익은 이번 접속에서만 유지됩니다. 이동/막대 속도는 테스트 조정값이며 최종 게임 규칙이 아닙니다.

별도로 사용할 수 있는 [앰버랫 B 모델](dist/Emberrat-B.rbxmx)도 제공합니다. 포획 테스트 파일에는 이미 들어 있으므로 테스트할 때 따로 삽입하지 않아도 됩니다.

## 개발 파일
- `src/shared/Config.luau`: 앰버랫 정보, 성장 기획 설정, 포획 규칙, 테스트 조정값
- `src/shared/CaptureRules.luau`: 거리와 미니게임 판정 계산
- `src/shared/BagRules.luau`: 가방의 개별 몬스터와 접속 중 수익 계산
- `src/server/CaptureServer.server.luau`: 서버의 탑승·포획 처리
- `src/client/CaptureClient.client.luau`: 입력, 카메라, 한국어 안내 화면
- `src/client/RideAnimator.luau`: 탑승 중 기본 부품의 다리 움직임과 좌우 기울기
- `tools/build_place.py`: 소스를 포함한 Studio 파일 생성 (Python 표준 라이브러리 사용)
- `tools/emberrat_model.py`: 선택한 B 기본형의 수정 가능한 모델 형태/색상 데이터

코드 변경 후 `python tools/build_place.py`를 실행하면 테스트 파일을 갱신합니다. 사용자는 별도 플러그인 설치나 코드 복사 없이 생성된 파일을 열면 됩니다.
